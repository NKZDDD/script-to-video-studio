# 好漫剧（75api.com）要接，但规格拿不到

日期：2026-08-26
起因：用户原话——「需要按照接入服务商守则接入这家"好漫剧"服务商sd2.5和H3一定要接入成功」，
附件是 `好漫剧API对接文档 - 飞书云文档.html` 和同名 `_files` 目录。

## 我查到的

### 一、附件里没有请求规格

飞书导出的 HTML **只序列化了大纲块**，正文块（参数表、cURL 示例）是登录后从服务端
懒加载的，不在文件里。三种办法都挖过：

1. 剥标签取可读文本 → 91 行，全是页面框架和目录
2. 正则抓 `initialAttributedTexts` → 0 段（`attribs` 里有花括号，非贪婪匹配跨不过去）
3. 逐字扫 `"text":{"0":"…"}` → **24 段，全是标题**

关键词计数印证了这一点：

```
/v1/videos      0 次        task_id       0 次
aspect_ratio    0 次        sd-2          0 次
sd2.5           0 次        duration     31 次（全在 CSS 里）
```

只有 2 个代码块因为渲染进了可见 DOM 而幸存：香蕉2 的 cURL、香蕉 Pro 的响应片段。
`_files` 目录 19MB 全是飞书前端的 js/css，`grep 75api|minimax_h3|sd2` 一个都没有。

### 二、但模型表拿到了（实拉，不是猜的）

这家是 **New API 网关**（`/v1/models` 回 `{"type":"new_api_error"}`），
和小霸龙、M86 同一套代码，所以 `/api/pricing` 公开可读。**28 个模型**：

| 用户要的 | 实际模型名 | 单价 | 同族其余 |
|---|---|---|---|
| sd2.5 | `sd-2.5-c1` | 3.3/次 | `sd-2-c1` 2.3、`sd-2-c6` 3.3、`sd-2-fast` 1.8 |
| H3 | `minimax_h3` | 0.04/次 | — |

其余视频：`sora3-933` 4.3、`sora3-fast` 1.5、`veo-3.1-fast-generate-preview` 0.5、
`grok-1.5-fast-10s` 0.4、`grok-imagine-video-1.5-preview` 0.85、
`gemini-omni-flash-preview` 0.5。
图片：`gpt-image-2` 0.04、`gpt-image2-2k` 0.08、`gpt-image2-4k` 0.12、
`nano-banana-pro-2k` 0.09、`-4k` 0.18、`nano-banana-2-2k` 0.08、`-4k` 0.15。
分组只有 `default` / `vip`，倍率都是 1。

### 三、两处矛盾 —— 正是不能猜的地方

1. **文档目录里根本没有 SD 章节。** 七节是 GROK / 香蕉 / GPT-image-2 / Sora2 /
   VEO / Omni-flash / minimax_h3。而 pricing 里有 4 个 `sd-*` 模型。
   也就是说 `sd-2.5-c1` 存在、但这份文档没写它怎么调。

2. **香蕉的模型名，文档和 pricing 对不上**：
   文档示例用 `nano-banana2` 和 `firefly-nano-banana-pro-2k-16x9`，
   pricing 里是 `nano-banana-2-2k` 和 `nano-banana-pro-2k`。

第 2 条尤其要紧：**这轮已经在鹤和小霸龙上各栽过一次**——照文档抄的模型名，
实拉发现鹤有 9 个已下线（含默认的 `sd2-pro-720p`）、小霸龙 20 个只剩 2 个。
模型名只能来自 `/v1/models` 或 `/api/pricing`，不能来自文档。

### 四、还缺一把 Key

`/v1/models` 要鉴权（401）。没有 Key 就没法：
- 确认这个账号实际能用哪几个模型（New API 按令牌分组过滤，pricing 是全量表）
- 确认 `minimax_h3` 走 `/v1/videos` 三步式还是 `/v1/chat/completions`
  （文档大纲写「提交/查询/获取内容」= 三步式，但 pricing 里所有模型的
  `supported_endpoint_types` 都是 `["openai"]`，两者对不上）
- 校准 `sd-2.5-c1` 的字段形状

### 五、范围

接一家服务商在本项目里涉及：
- studio：`core/providers/haomanju.py` + `_BUILTIN_ORDER` 登记 + `tests/test_haomanju.py`
- ComfyUI：`haomanju_nodes.py` + `__init__.py` 两处（import 元组 + module 循环）
- 两边模型清单必须逐项一致

# 刷新服务商后两把 Key 变成一把

用户在打包期间反馈：“超模点击拉取服务商后2个key会变成一把key”。

已查：Studio 当前超模表单固定显示图片 1K、图片 4K 和视频三个分组；刷新模型接口只更新模型缓存，不写密钥；重新扫描服务商只补并发配置。前端在刷新后重建整个设置表单，尚未保存的输入会被清空。批量程序另有自己的设置页面，不能据此推断用户指的是哪一处。

需要确认：发生在 Studio 还是批量程序；“变一把”是输入框变成一个，还是仍有两个框但只有一个显示已配置。确认前不把推测当作根因。

用户回答：发生在 Studio 的服务商设置；具体是框数变化还是已配置状态变化，仍待确认。当前电脑的 8770 端口未能读取到正在运行的 Studio，不能直接核查用户所见页面。

# Agent 工作台 EXE 发布

用户指令：“打包exe”。

## 原因与修改

工作台已切到新的 HTTP 入口，但打包脚本仍访问旧服务商、模块和提示词接口，并只检查旧页面的内联脚本。旧接口已停用，新页面使用独立 JS，因此旧自检既会把新程序误判为无法启动，也无法发现新脚本遗漏或语法损坏。

发布检查改为从 EXE 自检报告核对模块和全部资源散列，实际访问 Agent 页面、JS、CSS、启动数据和线程统计，再创建隔离项目核对绝对路径契约和完整技能快照。页面语法检查覆盖外部 JS；线程统计依赖改为发布必需，显式收集隐藏导入。随包提供新工作台使用说明。

这样能在交付前发现新页面缺文件、完整技能包漏带、旧文件混入和线程统计缺失；自检使用隔离目录，不向服务商发起收费请求。

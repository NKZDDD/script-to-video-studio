# 按已确认原型实施 Agent 生产工作台

用户指令：“按照原型实现”。此前已确认按功能包隐藏入口，第一版不做多人账号；对外称 Agent；密钥、基础并发、当前线程和建议并发不能被简化版隐藏。

## 定性与范围

旧入口把文字分析、材料导入、生成与后期混在一套页面里，生产 worker 还能通过延迟工厂触发文字模型改写。只替换文字标签不会改变材料交接方式，也不能保证生产时不再调用文字模型。

本次按已评审原型建立四页工作台和五步创建向导。复用现有图片/视频适配器、文件下载与错误分类；新 HTTP 入口只开放生产工作台路由，旧文字分析接口返回停用提示。原有内部模块保留以支持旧任务字段和历史回归，但不再通过产品入口启动文字分析。

默认采用原型方案：用户把模板交给 Agent；旧项目可查看和继续生产；不自动向服务商提交任务、不自动迁移或删除原项目。

## 实现

- 项目搜索、类型/状态/归档筛选、排序、创建向导；完整 51 文件技能包固定到每个新项目，用户选项和绝对生产路径写入锁与 Agent 模板。
- READY 发布边界、字节散列、项目/版本/路径/引用/循环/交接板同源检查；接收后存 Studio 快照。新内容必须使用新输出名，避免旧成品被认成新版。
- 资源分类/实体树、按集和目录查看、筛选与勾选持久化；共享资源不复制；缺少所选依赖可显式补选。文件校验通过的产物复用，失败/无效文件明确报错。
- 五类生产各自保存服务商、模型和并发；预览能力、密钥与依赖后启动真实队列；批次冻结任务、提示词、参数，保留停止和逐项错误。新队列不调用自动改写。
- 服务商声明驱动的密钥/分组/多账号设置、上传设置、全局与服务商并发；实际线程、CPU、内存和建议并发固定可见。没有足够采样就显示待采样。
- 并发闸门用共享在途计数热更新，降低上限时等待在途数回落。账号额度不会被配置轮询冲掉，排队任务可在取消后退出。
- 可选字幕与后期保留按集合成、识别/SRT 复用与字幕样式烧录；运行参数强制关闭文字优化和翻译，既有项目中的旧文字模型配置不进入这条路径。结束记录可跨重启查看。

## 修完能避免什么

Agent 不再把文件交到无关目录后要求用户二次导入；半份发布或错项目材料不能进入收费生产；筛选不会清空隐藏的勾选，缺少必要上游不会被静默略过；新版本和修改选择不会改变已排队批次；降低并发不会额外放出一批请求；简化界面保留实际生产必需功能。

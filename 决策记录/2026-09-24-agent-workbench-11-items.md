# Agent 工作台第二轮 11 条：删除、参考图可视、产物分类、秒数、并行抽卡、多集合成

日期：2026-09-24
起因：

> 1、删除资产功能（单个删除和按依赖删除，选项是否全删除父子链路兄弟链路）
> 2、生成中的参考图需要可视并且可跳转，哪个依赖没有满足是可以看的
> 3、产物中的预览也需要分类和旧版一样固定资产、连续状态资产等并且有删除等功能
> 4、生产的资产分类需要有按集后有资源类型，或按资源有集的单位
> 5、任务明细 点击蒙版处可以自己消失
> 6、分段视频需要能选秒数
> 7、重试的抽卡不需要等待全部完成，只需要参考依赖关系
> 8、网页视频查看可以拉动进度条
> 9、视频合成的多集和全集也都需要
> 10、重试次数需要展示出来
> 11、点击重新抽卡直接开始跑不需要点击开始生产

## 我查到的

1. **删除**：现在没有任何删除入口。「做过没有」只看输出文件在不在（`core/agent_runtime.py` `valid_output`）。任务之间有两套关系：参考图依赖（`dependencies`，来自 `reference_images` / `handoff_refs`，`core/agent_projects.py` `view`）和资源树父子（`resources[].parent_id`）。
2. **参考图不可见**：资源详情里参考图只列文字（`web/agent.js` `renderDetail`）。运行中等上游时，执行器把任务留在 `pending`、不写原因（`core/executor.py` `run_batch` 的 `hold` 分支），任务明细里看不到它在等谁。
3. **产物页**：`outputs()` 是一个平铺网格，只能按「图片 / 视频」筛。旧版资产库按「人物身份 / 场景 / 道具 / 连续状态资产…」分组（`core/explorer.py` `_CAT_CN`）。
4. **生产树**：三种模式——按资源分类（类型 → 父子树）、按集（集 → 平铺）、按磁盘目录。缺「集 → 类型」和「类型 → 集」两级。
5. **任务明细**：是一个 `<dialog>`，只绑了关闭按钮，点背景不关。
6. **秒数**：来自 Agent 发布的 `params.duration`。页面只有打开「高级参数」功能包时才有一个对所有视频生效的文本框覆盖。
7. **抽卡要等整批**：`start()` 开头只要本项目有任何在跑的批次就拒绝（`core/agent_runtime.py`），`reroll` 接口也一样拒绝（`server/agent_api.py`）。
8. **视频拖不动**：`/file` 一次把整个文件读进内存、只回 200，不认 Range 请求（`server/app.py` `do_GET`）。浏览器拿不到「从第 N 字节开始」的数据，就没法跳到中间。
9. **合成**：`assemble.build` 只收一集。
10. **重试次数**：只在数据目录 `config.json` 的 `defaults.max_retry`，页面上没有。
11. **重新抽卡**：只挪备份 + 勾选，还要再点「查看生产计划 → 开始生产」。

2、4、5、8、10、11 以及 3 的分类部分，做法只有一种，直接做。下面四个要你定。

## 要你定的

### 1. 删除到底删什么、连带范围怎么算

- **A（推荐）**：删的是已生成的文件（图 / 视频），挪进 `07_检查与记录/回收站/<时间>/`，保留原来的相对路径，可以找回；任务留在树上，变回「待生产」。删除对话框里三个勾选，删之前列出每个将被删的文件：
  - 子链路：引用它做参考的下游，一直往下。**默认勾上**——它们是拿旧图做出来的，旧图没了它们就对不上。
  - 父链路：它引用的上游，一直往上。默认不勾。
  - 兄弟链路：和它共用同一个上游的其他任务。默认不勾。
  - 好处：不碰 Agent 的发布，误删能拿回来。代价：回收站占盘，要自己清。
- **B**：同 A，但直接删掉文件，不进回收站。好处：省盘。代价：误删只能重新生成、重新付费。
- **C**：连任务一起从树上去掉（本地隐藏）。代价：Agent 下次发布新版本时又会出现；隐藏的任务也不会被生产。

我倾向 A：这个项目最贵的失败是「钱花了、东西没了」，回收站是唯一能撤销的形状。

### 2. 秒数选在哪一层

- **A（推荐）**：两层都给。视频那一行一个「统一秒数」下拉（跟随任务 / 模型支持的档位），每段详情里再一个单段下拉，单段优先。只改秒数、不改提示词——提示词是按原秒数写的时间窗口，页面会提醒这一点。
- **B**：只给每段单独选。
- **C**：只给整批统一选。

我倾向 A：整批换模型时要一次改完，个别段要单独调，两种场景都常见。

### 3. 多集 / 全集合成出什么

- **A（推荐）**：勾若干集或点「全集」，按集顺序拼成**一个**文件（例如 `EP01-EP05_MASTER_….mp4`）；清单照样能去段、调顺序、插外部视频。
- **B**：勾选的每一集各出一个成片文件，一次跑完多集；清单编辑只在单集时可用。
- **C**：两种都给，对话框里选。

我倾向 A：单集成片现在已经能出，缺的是跨集的那一个文件。

### 4. 「不用等整批」只给重新抽卡，还是所有生产

- **A（推荐）**：所有「开始生产」都可以在别的批次还在跑时开始，只要这次的任务和在跑的不重叠；依赖在别的批次里生成的，等它生成好再开跑。
- **B**：只放开重新抽卡，其他照旧要等整批结束。

我倾向 A：重新抽卡改成点了就跑以后，它自己就是一个在跑的批次。只放开抽卡的话，抽卡那几分钟里「开始生产」照样点不了。

## 你的回答

1. A：删文件进回收站，任务留在树上；子链路默认勾上。
2. 「在生产的服务商选择模型的时候给，这个秒数指的是服务商的传参」——只在生产页视频那一行、选模型的地方给一个秒数下拉，值就是发给服务商的时长；不做每段单独选。
3. A：多集 / 全集按集顺序拼成一个文件。
4. A：所有开始生产都能在别的批次运行时开始，只要任务不重叠。

## 怎么修的

- **删除**：新增 `core/recycle.py`。连带范围按参考图依赖加资源树父子一起算；文件挪进 `07_检查与记录/回收站/<时间>/`，保留相对路径并写 `删除清单.json`，同时清掉这个输出的「已提交」记录。正在生成的任务拒绝删除。入口：生产详情和产物卡片上的「删除…」。
- **参考图可视、可跳转**：详情里参考图改成缩略图 + 状态；没好的列在上方，点图或任务名跳到树里那一项（自动展开所在目录）。执行器给还没派出去的任务写明在等什么（`等待上游：X、Y` / `排队中：等…并发名额`）；任务明细把说明里的任务名做成可点的链接，状态显示中文。
- **产物分类**：按固定资产 / 连续状态资产 / 场景状态图 / 交接板 / 区域图 / 分段视频分组；固定资产按语义再分，分段视频按集再分。卡片上有原文件、在生产树中查看、重新抽卡（视频）、删除。
- **生产树**：新增「按资源类型 → 集」「按集 → 资源类型」两种两级分组。
- **任务明细**：点对话框外面收起。
- **秒数**：生产页视频那一行加「秒数」下拉（模型声明的档位或设置里手填的档位），值写进 `production-settings.json` 的 `video.duration`，生产计划时覆盖每段的 `params.duration`，也就是发给服务商的时长。高级参数里重复的秒数框去掉。
- **不用等整批**：`start()` 不再因为本项目有任何在跑的批次就拒绝；改成排除正在别的批次里生成的任务，依赖它们的在 `ready` 里等那一项结束（失败就当场标失败）。`reroll` 接口只拒绝这一段自己正在生成的情况。
- **视频拖动**：`/file` 支持 `Range`，回 206 和 `Content-Range`，按块读，不再整份读进内存。
- **多集 / 全集**：`assemble.plan/build` 接受集列表，按集顺序拼成一个文件，全集文件名带 `FULL_`，旁边的清单 json 记下所选集。
- **重试次数**：「设置 → 并发与重试」里可改（0–5），生产计划、生产页服务商栏和任务明细（每条重试几次 / 最多几次）都显示。
- **重新抽卡直接开跑**：挪备份后立刻 `start(only=[这一段])`；开不了跑时把原视频放回原处并报原因。

## 为什么会有这些问题

- 抽卡要等整批、分段视频看起来「不并发」，根子是同一个：`start()` 用「这个项目有没有在跑的批次」代替「这些任务有没有在跑」。这条防的是同一段在两批里各付一次钱，但它把不相干的任务也一起挡住了。重新抽卡原来只挪备份、不开跑，所以一直没碰到这道闸。
- 进度条拖不动：`/file` 最早是给图片预览写的，整份读、整份回，从来没回过 206。图片不需要从中间取，视频一需要，浏览器就把进度条锁死。
- 看不出在等谁：等上游的判断只返回给调度器用来决定派不派，从没写进任务状态；页面只拿得到一个 `pending`。

## 修完能避免什么

- 以前一批 40 段视频在跑时重新抽一段，要等 40 段全部结束才能点；现在点了就跑，只等它自己的参考图。
- 以前一段视频卡在「pending」，要翻日志才知道是在等参考图还是在排并发；现在任务明细和详情里直接写着「等待上游：LOOK_A1（另一批在生成）」，点名字就跳过去。
- 以前删错一张图只能重新生成、重新付费；现在从回收站拷回原位置就行，而且删之前能看到会连带哪些下游，不会留下「参考图换了、视频还是旧图做的」这种对不上的成品。
- 以前换了只支持 4–12 秒的模型，30 秒的段只能让 Agent 重新切段；现在可以在视频那一行直接选服务商支持的秒数。

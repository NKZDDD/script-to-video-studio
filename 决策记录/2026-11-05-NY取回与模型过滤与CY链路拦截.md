## NY 任务取回

任务本身没有丢。用用户提供的 Key 直接查询：

- `GET /v1/videos/vcr1_98c62f87…` 返回 `status: completed`、progress 100、Seedance2.5ny2、30s 480p、已结算 12 元；
- 该响应只有 status、progress、billing，没有任何结果 URL；
- `GET /v1/videos/vcr1_98c62f87…/content` 返回 200、`video/mp4`、6,087,689 字节。

原实现只等轮询响应里的 URL，状态一旦变成 completed 就取不到地址，抛“任务完成但未取到结果”；续查又走同一套解析，所以这个任务 ID 永远取不回。

修复（已随 `3b1dc64` 进入仓库）：新增 `_result_url`，响应里有 URL 就用，没有但状态已完成则回落到 `{base_url}/v1/videos/{id}/content`（下载自动带鉴权头）；并覆盖 `resume`，让续查也走这条路径，不再依赖基类重放。实测用该 Key 走修复后的 `resume` 成功落盘 6.08 MB mp4。

## 模型清单过滤

NY 的 `/v1/models` 混着 minimax 的语音合成模型（`speech-2.6-hd`、`speech-2.6-turbo`、`speech-2.8-hd` 等 4 个）以及纯文本模型。适配包没有声明类型时，客户端把它们归入“未识别类型”并提示更新适配包。Studio 只做图和视频，这类模型本来就用不上。

修复：新增 `_KIND_PATTERNS`、`_usable_kind` 和 `filter_catalog`。

- 能力表 `IMAGE_MODELS` / `VIDEO_MODELS` 命中的直接归位；
- 其余按名称特征归类（图片：`banana`、`seedream`、`flux`、`sd2.5` 等；视频：`seedance`、`sora`、`veo`、`kling`、`h3`、`wan`、`sd…` 等）；
- 语音、纯文本、编辑类模型返回空类型，从目录中直接剔除，不再产生提示；
- 命中的行显式标注 `type`，新旧客户端都能正确归类。

## CY 链路拦截（无代码改动）

现象：用户机器上 CY 报“无法连接模型目录”，同网络其他站点正常。

证据链：

| 测试 | 结果 |
| --- | --- |
| TCP 连 `154.12.46.253:443` / `:80` | 均可建连，说明不是路由、DNS、端口问题 |
| 443 带真实 SNI | ClientHello 后被 RST |
| 443 带 `www.baidu.com` 的 SNI 连同一 IP | 握手成功，服务器本身正常 |
| 80 带真实 Host | 被 RST（无 TLS 也拦，排除证书与 TLS 版本） |
| 80 带 `example.com` 连 `1.1.1.1` | 403 正常响应 |
| 80 带真实 Host 连 `1.1.1.1` | 被 RST，与目标 IP 无关 |
| 80 带真实 Host 连百度（走 IPv6） | 403 正常，拦截只作用于 IPv4 |
| 走 Clash 全局模式 | 401，加密隧道下正常 |

中国侧另一网络实测该域名 401、`Host: ai…` 到 `1.1.1.1` 返回 403，说明域名本身没有被大范围封禁，问题在那台机器的 IPv4 出网链路：按 Host/SNI 匹配并重置。

另一个关键点：托管模式下请求被强制直连——后台下发 Key 时写入 `proxy='direct'`（[cloud_config.py](file:///f:/script-to-video-studio/core/cloud_config.py#L129-L131)），模型目录默认也是 `'direct'`（[model_catalog.py](file:///f:/script-to-video-studio/core/model_catalog.py#L64-L66)）。`apiutil` 把 `'direct'` 翻译成空 proxies，等于显式禁止系统代理，所以 Clash 的“系统代理”和“全局模式”对客户端都无效。批量软件里看到的“CY：无法连接模型目录”就是这个原因。

结论：不是服务端、不是 TLS 版本、不是 API Key、不是软件 bug。可用的规避方式：

1. Clash 开 TUN 模式（网络层接管），并让该域名走节点：全局模式即可，规则模式下需加 `DOMAIN-SUFFIX,cangyuansuanli.cn,<节点>` 且排在 `.cn` 直连规则之前；
2. Proxifier 之类的进程级强制代理；
3. 让该机器直连通路恢复（IDC/网关白名单、换网络、或服务商提供备用域名）。

注意：在 Studio 里给服务商填代理无效，请求仍交给 Clash，规则判 DIRECT 依旧是直连。

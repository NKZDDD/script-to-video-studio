# H3 参考图不设本地张数限制，页面提示词保存独立于 Agent 发布

日期：2026-10-09

## 需求与定性

用户要求：“按照文档阿珂H3也是没有锁才对，提示词开放页面修改否则都需要去文件修改很麻烦”。

- 阿珂 `_limits()` 将 `minimax_h3-` 设置为 9 图，其他 H3 名称落入默认 4 图。目录合并后的通用视频能力还可能在生产预览中施加 10 图上限。请求适配和生产预览是两道独立的拦截。
- 页面提示词保存原先重新制作 READY 并执行整个 Agent 发布校验。只修改文字也要求全部任务参数、项目锁、协议、资源关系符合当前契约；旧项目或遗漏参数的已登记任务因此无法保存。读取所有其他提示词时，任意缺文件也会阻止保存。

## 修改范围

- H3 名称不区分大小写，适配器发送全部参考图，不加 4/9 图张数限制，不裁图。其他视频模型保留原有明确限制，视频/音频支持规则不扩展。
- 阿珂能力声明 H3 模型匹配规则；拉取或加载模型目录时覆盖旧图片数量限制，令生产预览使用 `refs_unlimited`。同步维护主程序与 `provider_patches/zz_ake_image.py`。
- 本次按用户明确要求取消客户端 H3 限制；没有付费测试，也没有据此宣称服务商实际接受任意多图。官网主页只能读取到 JavaScript 壳，尝试文档入口未取到 H3 文档正文。
- 页面编辑为 Studio 本地修订，保留 rNNNN 递增、旧产物和受影响下游的新输出路径；不调用 Agent 发布验证，不伪造 READY。最后原子切换 active-plan，保证保存失败时原活动计划不变。
- 复制可读的其他提示词以保持不可变快照及交接包完整性；其他任务缺文件时保留其原路径待修复，不阻止本条编辑。保存空文字、覆盖他人新修改、编辑归档项目和越界路径仍被拒绝。
- 更新任务指纹，后续 Agent 的正式发布仍执行完整契约检查，未改动任务可沿用输出。
- 生产预览检查合并页面选择后的参数：缺尺寸/比例/时长时提示在页面补选，提示词已保存。已有服务商任务 ID 的取回分支仍先执行，不要求补齐新建参数。
- UI 明示“缺少生产参数不影响保存，可在生产前补选”。没有打包新的 EXE。

## 验证

- 全量回归：3160 passed，264.92 秒，日志 `outputs/h3-edit-full-20261009.log`。
- 全量启动后补齐了可读提示词快照复制及两项测试；最终针对性回归 53 passed，13.99 秒（页面编辑、H3 适配、阿珂图片、模型目录）。其中覆盖 16 张参考图完整请求、12 图生产预览、旧目录 4 图声明不重新锁定、其他模型保留上限、缺契约/参数/其他提示词仍可保存、连续编辑、存盘故障保留活动计划、旧批次快照、后续 Agent 发布复用、交接包包含全部可读提示词。
- 补跑提示词与交接包模块：33 passed，1 项导入目录重命名遇到 Windows WinError 5；该失败用例在独立短路径单独复跑 1 passed（0.93 秒）。全量中的同一用例也通过；未据此修改无关导入逻辑。
- `node --check web/agent.js` 和 `git diff --check` 通过；主程序与阿珂外挂文件字节一致。
- 以上没有调用付费生成，也没有修改用户真实项目。

## 避免的问题

H3 不再因名称不同被程序拦在 4/9/10 图，也不会偷偷删参考图。旧项目可在页面保存提示词，生产参数问题留到生产预览显示；旧产物和已运行批次继续使用原快照，之后 Agent 发布仍需满足契约。

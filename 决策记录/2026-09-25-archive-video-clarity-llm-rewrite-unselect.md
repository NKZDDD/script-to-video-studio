# 归档能否恢复；视频清晰度；恢复 LLM 改写重试；开始生产后取消勾选

日期：2026-09-25
起因：

> 现在项目的归档是可以还原吗？如果不行需要加上二次确认，视频服务商也需要选择清晰度，还有LLM砍了重试机制就没了这个需要恢复，也就是LLM只作用于自动调整提示词然后重试任务的机制，选完提交生产任务后就不需要继续选中避免二次提交或重试

## 我查到的

1. **归档能恢复**：`/api/agent/archive` 只改项目元数据里的 `archived` 标记，不动文件；项目列表在「项目状态」选「已归档」时
   显示这些项目，按钮是「恢复」。所以按原话不加二次确认。问题在于入口藏得深：归档后项目直接从列表消失，页面一句话都没有。
2. **视频清晰度**：只在打开「高级参数」功能包后有一个文本框覆盖，平时选不了。
3. **LLM 改写重试被关掉了**：改写本身（`core/soften.py`：审核拒绝 → 分四级改写 → 每版验收 → 重发）完整还在，
   是 Agent 工作台把它关了 —— `agent_runtime.preview` 给每一类写死 `soften_rounds = 0` 和 `agent_mode = True`，
   `produce` 在 `agent_mode` 下直接出图不走改写；`start()` 也不给工作函数 LLM；设置页和启动数据把 LLM 全部剔掉了。
4. **勾选**：开始生产后勾选原样保留，批次结束后再点一次「开始生产」会把失败的那几条重新提交。

## 怎么修的

- 归档 / 恢复后提示一句：「文件都还在……在「项目状态」里选「已归档」，点「恢复」」。
- 视频那一行加「清晰度」下拉（和秒数同一格），值写进 `production-settings.json` 的 `video.resolution`，生产计划时覆盖任务参数。
  清晰度写在模型名里的模型（鹤的 `…-720p`，能力声明是 `[""]`）显示「由模型决定」、不可选。不支持的清晰度在生产计划里挡住并说清该去哪改。
  高级参数里重复的清晰度框去掉。
- LLM 只接回「被审核拒绝后改写提示词再重发」这一件事：
  - `preview` 的 `soften_rounds` 改成读 `defaults.soften_rounds`（默认 12，0 = 关）；`produce` 只在 `agent_mode` 且轮数为 0 时直接出图。
  - `start()` 新增 `llm_factory`，传给出图 / 出片工作函数；开始生产和重新抽卡都用 `app.build_llm(cfg)`。
  - 设置页新增「提示词改写 LLM」：Base URL、API Key（不回显，留空不改）、模型、改写轮数。启动数据只回地址、模型、配没配 Key、是否齐全。
  - 生产计划写明被拒后会不会改写、最多几轮；LLM 没配好时写明不会改写。
- 开始生产成功后，把这一批勾选的任务全部取消勾选（`A.select(..., False)`）；重新抽卡开跑后那一段也取消勾选。

## 为什么会有这个问题

Agent 工作台上线时定的边界是「Studio 不做文字分析」，实现时把 LLM 连同改写重试一起砍了 ——
而改写重试不是分析，是出图出片被审核拒绝时的补救，砍掉后被拒的任务只能失败、人工改提示词。
视频清晰度、归档恢复这两处是入口只放在高级参数 / 筛选里，平时看不到。
勾选保留是早先「选择自动保存」的设计，和「交出去的不再重复提交」冲突。

## 修完能避免什么

- 以前一条被审核拒绝就直接失败，要人自己改提示词；现在按四级阶梯自动改写重发，改写前后全文都留档，删戏或换脸的改写不会发出去。
- 以前视频清晰度只能开高级参数手填；现在视频那一行直接选。
- 以前归档后项目消失，看起来像被删了；现在提示在哪里恢复。
- 以前批次结束后再点「开始生产」，失败的会被悄悄重新提交、重新计费；现在要人自己再勾上。

# 沧元图片与视频全模型接入、设置默认生产目录

日期：2026-10-13

## 用户需求与范围

先为沧元视频出外挂，后追加：使用新 Key 接入全部模型、开放默认地址修改，重新打包应用。
已询问：71 个模型中是否新增语音识别、配音、音乐入口？
用户选择：先接入全部图片和视频（推荐）。本次范围为 32 个图片 + 34 个视频。
Key 只用于授权查询和本机配置，不进入代码、决策记录或发行包。

## 定性

原沧元适配器只声明 image，视频在生产页不会出现。
图像旧快照缺少 doubao-seedream-5-0-flash，部分逐型号参考数量和比例候选已经更新。
默认目录保存在 config.json 的 projects_dir；创建页 base 仅用于本次创建，不更新默认。
Agent 设置页只展示路径，旧路径修改接口也没有保留此前目录的项目登记，切换后会找不到旧项目。

## 实施

视频新增独立 cangyuan_video 入口，与 cangyuan 图片配置隔离，可使用同一把全能力 Key。
全部型号按官网 docs-static 文档适配；只读 GET /v1/models 已返回 71 型号，其中图片视频 66 个。
清晰度、时长、参考图/音频/视频限制按型号；不裁图、不默改时长；保存任务 ID 续查。
图片新增 Flash，同步逐模型参数；补齐模型类型识别，语音音乐不混入图片视频下拉。
设置 → 功能包与路径新增默认生产目录表单；检查绝对路径及可写性，持久保存。
更换默认目录时保留旧目录登记，新项目用新默认，已有项目原地保留。

成品复核发现视频编辑型号需要参考视频，但旧页面只有参考音频入口。新增视频任务详情的 HTTPS 视频链接添加/移除入口，独立侧车文件持久化，不改原 tasks.json；逐模型校验，并随批次冻结，按顺序传到 reference_videos。已有任务 ID 的取回机制不变。外挂可更新协议，但旧 EXE 没有这个新入口时需要升级 EXE。

# 对外批量版复用现有账号和 Key 分配

日期：2026-10-29。
用户确认：按账号下发 Key 和模型、记录用量自行核算，不增加余额、价格、扣费、退款或账单。

机制：respect_batch 的发行配置原先编译封装 Key 与固定模型列表，与现有登录服务无连接；认证服务的版本类别又仅接受 all/v34/v61，直接套用会使不同应用共用更新门槛。

范围：在独立批量项目接入登录、内存配置、模型选 Key、原用量接口和原 R2 签名上传；本仓库仅为认证服务增加 batch 类别、界面选项和统计筛选。账号库与授权模型不改变，Studio 客户端不改。

完成后避免：换 Key/调整模型不再需要把新凭据封进批量 EXE；批量包不再误受 Studio 最低版本约束；重复轮询不会增加生成次数。用量上报仍不作为可信计费账本。

验证：批量客户端 115 项通过；认证服务 141 项通过；Studio 全量 3737 项通过、1 项跳过。Edge 无头浏览器验证登录、模型刷新、后台名称同步、输出目录/并发保留、退出登录及页面不包含上游地址/Key；无付费生成、未改线上发布策略。

# Studio 独立窗口、安装器与在线更新

日期：2026-10-20
起因：用户要求 EXE 升级增加更新功能，不再启动命令行窗口，使用安装器安装；随后明确“我指的是 studio”。

## 定性和范围

`run.py` 通过 webbrowser 打开外部浏览器，并在主线程运行 HTTP 服务；`打包exe.py` 显式使用 `--console` 和默认 onefile。现有登录服务没有客户端版本发布接口，所以仅上传新版 EXE 不会让旧客户端获得更新能力。

本次范围是 Studio 主程序及其登录服务，不是 DA 执行端，也不接入 App Server。两套生产体系共用启动和设置页面，均保留。

## 实施约定

- 用系统 WebView2 显示现有工作台；主程序无控制台窗口，诊断日志落盘。
- 安装器安装目录式包，创建快捷方式、支持卸载与覆盖升级；不删除项目、密钥、外挂或数据目录。
- 后台管理版本信息；Studio 检查版本、下载校验，用户点击安装后退出并启动安装器。
- 正在生产时允许检查和下载，禁止安装；不能为了更新强杀生产任务。
- 沿用登录服务域名；提供升级包供用户部署，不假称线上已升级。
- C 盘空间较少，构建与临时目录使用 D 盘。

## 追加决定：移除字幕

用户明确“字幕直接砍掉”。Studio 的创建页字幕选项、字幕后期入口与接口、命令行直通、两套流水线的字幕步骤一并移除；功能包改称“成片合成”。新安装包不含 VideoCaptioner、audioop、pydub、字幕样式或字幕专用模块，FFmpeg 仍负责视频合成。

原因是原打包脚本把可选字幕能力列为硬依赖，还会收集整套识别与翻译模块；只隐藏按钮仍会占用安装包并允许旧配置触发。移除所有执行入口并在打包时排除后，旧项目打开不会自动启动字幕处理。

仓库内独立的 `subtitle_app` 是另一产品，保留它的源码和独立测试，但不随 Studio 安装。旧项目的 SRT、带字幕视频和自定义样式文件不删除；剧情中的招牌、对白文字等创作内容不属于这次功能移除。

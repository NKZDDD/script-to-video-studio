# 字幕配置搬到剧维度

## 起因

用户原话：

> 字幕的配置应该在剧的维度，而字幕的LLM配置放在设置里是没问题

## 我查到的

**这个项目已经有一套「剧级设置」的做法，字幕该照它走，但不能用它那张表。**

剧级设置的机制在 `core/settings.py`：`FIELDS` 声明字段 → 存在
`pj.meta()["settings"]` → `/api/project/settings` 一并下发 schema 和值 →
前端通用渲染（`renderBrief`）。面板在**流程页**，和「本剧的提示词」
「项目基础信息」放在一起。继承关系是既有约定：

```
内置 → 全局基础（设置页）→ 本剧      下面的盖上面的
```

**但字幕配置不能塞进 `settings.FIELDS`。** 那张表里的字段是**要进提示词
模板**的（`mapping()` 把它们渲染成 `{{PLACEHOLDER}}`），而
`settings.unused()` 专门用来找「定义了但一份模板都没用的设定」，
页面上会挂一条警告「这几组设置现在一个字都进不了提示词」。
字幕配置进的是 VideoCaptioner 的 `config.toml`，一个占位符都不占 ——
放进去必然被标成「填了也没人看」，而它明明有用。

所以要另开一处剧级存储：`pj.meta()["subtitle"]`。

### 现在这 16 项分别是什么性质

| 项 | 性质 | 归属（我的判断） |
| --- | --- | --- |
| 启用 | 这部剧要不要字幕 | 剧级 |
| 软/硬字幕 | 这部剧怎么交付 | 剧级 |
| 字幕样式 | 观感，和画幅语言绑定 | 剧级 |
| 微调七项（字体/字号/垂直间距/颜色/描边色/描边粗细/字符间距） | 观感 | 剧级 |
| 识别语言 | 这部剧说什么语言 | 剧级 |
| 翻译 / 翻译服务 / 目标语言 | 这部剧要不要双语 | 剧级 |
| 中/英每行最多几个字 | 和字号、画幅一起决定会不会溢出 | 剧级 |
| 压制画质 | 交付要求 | 剧级 |
| **LLM base / key / 模型** | 账号级 | **设置页**（用户已确认） |
| 识别引擎（必剪/剪映/whisper…） | **这台机器装了什么、哪家今天能用** | 见问题 2 |
| 单集超时 | 这台机器快慢 | 见问题 2 |

## 要你定的

### 1. 剧级要不要继承设置页的默认值

| 选项 | 代价 |
| --- | --- |
| **A. 继承（推荐）**：设置页保留一份「新剧默认」，剧级不填就用它 | 和这个项目已有的「内置 → 全局 → 本剧」完全一致；配一次所有剧都能用，某部剧要变再改那一部。多一层概念 |
| B. 纯剧级：设置页只留 LLM，字幕配置每部剧独立填 | 概念最简单，但**每建一部新剧都要重新挑一遍样式、字体、断句长度**。你现在一次批量建多个项目，等于建 N 个填 N 遍 |

推荐 A。选 B 的话我把设置页那张卡里除 LLM 之外的全部删掉。

### 2. 识别引擎和超时放哪

| 选项 | 理由 |
| --- | --- |
| **A. 都留设置页（推荐）** | 选哪个引擎取决于**这台机器装了什么**（faster-whisper 要下模型）和**哪家今天没限流**，不取决于剧；超时是机器快慢 |
| B. 引擎也做成剧级 | 如果你有的剧要用付费的 whisper-api 求准、有的用免费的必剪省钱，那它就是剧的属性 |
| C. 两个都做成剧级 | 一致性最好（字幕的事全在剧里），但这两项在剧之间基本不会变，多两个要填的框 |

### 3. 已经配好的全局值怎么办

如果选了问题 1 的 A（继承），这一问自动消解 —— 现有项目不填就继承，
行为和现在完全一样。

如果选 B（纯剧级），现有项目会**突然全部变成「没配字幕」**。要不要把
现在 config.json 里的那份值一次性写进所有已存在的项目？

用户的回答：

| 问 | 答 |
| --- | --- |
| 继承还是纯剧级 | **继承**：设置页留一份新剧默认 |
| 识别引擎放哪 | **也做成剧级**（超时仍留设置页） |
| 已配好的全局值 | 选了继承，这一问自动消解 |

## 怎么修的

### 归属

十七项按性质分成两组，**一个不剩**（有测试钉住 `DEFAULTS ==
PROJECT_KEYS | GLOBAL_ONLY_KEYS`）—— 漏一个的表现是它既不在剧级面板、
也没被标成全局专属，只能改 config.json，而页面上找不到。

| 剧级（13 项，可覆盖） | 全局专属（4 项，剧级盖不了） |
| --- | --- |
| 启用、软/硬字幕 | LLM Base URL |
| 字幕样式、字幕微调（七项） | LLM API Key |
| 识别引擎、识别语言 | LLM 模型 |
| LLM 优化开关、翻译、翻译服务、目标语言 | 单集超时 |
| 中/英断句长度、压制画质 | |

`optimize`（要不要花 LLM 的钱润这部剧的字幕）归**剧级**，
而 key 归全局 —— 开关和凭据分在两层，正是这次拆分的意思。

`llm_*` 做成剧级的话，40 部剧要填 40 遍同一把 key，而且 key 会散落在
40 个项目目录里跟着备份到处走。`timeout` 是这台机器快慢，不是剧的属性。

### 存哪

`pj.meta()["subtitle"]`，**不是** `settings.FIELDS`。

`settings.FIELDS` 里的字段是要进提示词模板的，而 `settings.unused()`
专门找「定义了但一份模板都没用的设定」，页面上会挂警告
「这几组设置现在一个字都进不了提示词」。字幕配置进的是 VideoCaptioner 的
`config.toml`，一个占位符都不占 —— 放进那张表必然被标成「填了也没人看」，
而它明明有用。

### 继承链

```
内置 DEFAULTS → 全局基础 config.json["subtitle"] → 本剧 meta["subtitle"]
```

和「本剧的提示词」同一条链、同一句文案 —— 不另起一套心智模型。

`merged(cfg, pj=None)`：不传 `pj` 就只到全局那一层。
**拿得到项目的调用方都必须传** —— 不传的表现是「这部剧填的东西不生效」，
而页面上照旧显示着填好的值。改到的调用点：
`run()` / `status()` / 两个 pipeline 的 `_subtitle_on()` 和 `_subtitle_note()`。

### 「没覆盖」和「覆盖成和全局一样」必须分得开

`project_values()` 只返回**显式覆盖**的键。分不开的话，改了全局默认之后，
那些「其实只是当时跟全局一样」的剧不会跟着变，而人以为它们是继承的。

所以清除覆盖用 **`None`**，不用空串 —— `style` / `language` 的空串本身
就是合法取值（「用 VideoCaptioner 自带的默认样式」），
拿空串当清除的话那个选择存不下来。

### 界面上的三个坑，都是「不报错但结果不对」那一类

1. **每项都是三态开关（跟随全局 / 自定义），不是普通控件。**
   用普通控件的话「没设过」和「设成和全局一样」长得一模一样。
   「跟随」那一行**写出继承来的具体值**（`跟随全局（烧录进画面…）`），
   人才知道不填会得到什么，不用切到设置页去看。

2. **勾「自定义」时初值取继承值，不取类型默认值。**
   取默认值的话，勾一下就悄悄把设置改了（本来继承 hard，
   一勾变成选项里第一个），而人只是想看看能改什么。

3. **保存时没勾的字段显式送 `null`。**
   只送勾了的字段的话，取消勾选永远不生效 —— 页面显示「跟随全局」，
   而 meta 里那个旧覆盖一直在起作用。

`when`（翻译服务只在开了翻译时显示）的判据用**生效值**而不是自定义值 ——
只看自定义值的话，继承了「开翻译」的剧看不到目标语言那一栏。

### 设置页那张卡

标题改成「这里是**新剧的默认值**」，并写清继承关系和去哪改单剧。
LLM 三项和单集超时各挂一句「所有剧共用，剧级盖不了」——
免得人在剧级面板里找 key 找不到。

## 实拍验收

全局：关字幕、无样式。本剧：开字幕 + 中文竖屏标准版 + 关掉 LLM 优化 +
微调（华文隶书 / 天蓝 #66ddff / 底边距 300）。

```
enabled       = True            (本剧)
style         = 中文竖屏标准版    (本剧)
optimize      = False           (本剧)
subtitle_mode = hard            (全局，继承)
llm_api_key   = sk-全局的        (全局，剧级盖不了)
```

抽帧确认：华文隶书、天蓝、位置上提，全部按本剧的设置渲染。
全局关着字幕而这部剧照样跑了。

## 为什么会有这个问题

字幕接进来时，我照着「服务商凭据、并发上限」那类**账号级**配置的样子
放进了 `config.json` —— 因为最初只是「装没装、key 填了没」。
等它长出样式、字体、断句长度这些**观感**参数，性质已经变了：
观感是剧的属性，一部竖屏中文剧和一部横屏英文剧不可能共用一套。

判据：**一个配置项，换一部剧要不要换值？** 要换就是剧级。
按这条重新过了一遍，十七项里十三项都是剧级。

## 修完能避免什么

- 一部剧换样式/字体/断句长度，不影响其它剧；批量建的 N 部剧
  仍然共享设置页那份底子，不用填 N 遍
- 某部剧单独关掉字幕（比如只交无字幕母版），不用改全局再改回来
- key 只有一个家，不会散落在 40 个项目目录里跟着备份走
- 改了设置页的默认值，所有「没自己设过」的剧真的会跟着变

# 生产流程五步：现状对照与缺口

日期：2026-09-24
起因：「我希望的流程是这样的现在的流程我是打算这样 手动codex（稳定之后转自动）—扔到自动化（涉及图片，视频的重试机制和回收保障）—跑出全部视频（视频拼接手动选择，涉及到重新抽卡完成后拼接）—剪辑（看剧本而定）—加字幕」

## 我查到的

| 步骤 | 现在有的 | 缺的 |
|---|---|---|
| 1 手动 Codex | 本机 Agent 契约；昨天加的交接包（跨机器） | 「转自动」是以后的事，这次不做 |
| 2 自动化（重试 / 回收） | 临时错误自动重试（默认 2 次）；上游失败时下游不提交；失败落盘；已有成品不重复生成；红鸟可以续查 | 见下面 2a、2b |
| 3 跑出全部视频 → 抽卡 → 手动选择拼接 | 按集拼接，按任务清单顺序，要求整集每一段都有效 | 见下面 3a、3b |
| 4 剪辑 | 程序里没有，在外部剪辑软件里做 | 这次不做 |
| 5 加字幕 | 工作台里只能处理 `06_成片` 下由 Studio 拼出来的 MP4；独立字幕工具可以处理任意视频 | 外部剪好的片子要放回 `06_成片`，或者用独立字幕工具 |

**2a 回收保障：除红鸟外，没有。而且轮询超时会让同一段重复付费。**
- 大部分服务商走通用轮询 `apiutil.poll`。超时抛出的是 `RETRYABLE`（`core/apiutil.py` 第 1088–1097 行），巨轮、好漫剧、Gate 各自的轮询超时也是 `retryable`。
- 执行器看到 `RETRYABLE` 会把整个任务重跑（`core/executor.py` 第 480–484 行，Agent 模式默认 `max_retry=2`）。重跑就是重新提交。
  所以一段视频在服务商那边排队久了一点，最多会被提交 3 次、付 3 次钱，前两个任务没人去取。
- 提交时网络断开（`RETRYABLE`）也会走同一条路；而服务商那边可能已经建好任务、开始扣费了。
- 任务号只写在报错文字里，程序重启或点「停止」之后，没有任何地方能把在途任务接回来。昨天给红鸟做的续查只覆盖红鸟一家。

**2b 换家：Agent 模式没有。** 旧版有「出图出片优先级」，一家挂了自动换下一家补剩下的。Agent 生产每类只用一家（`agent_runtime.start`），这家不行就停在那里。

**3a 抽卡：没有。** 每段只有一个固定的输出路径，文件存在就直接复用。想重做只有两条路：改提示词（会生成新的输出文件名），或者让 Agent 发新版本。没法「同样的提示词再出一条，挑一条好的」。

**3b 手动选择拼接：没有。** `/api/agent/assemble` 按任务清单顺序把整集拼起来，每段只能用那一个文件，不能换、不能跳过。

## 要你定的

### 1. 抽卡怎么留版本

- **A（推荐）**：每段可以有多个版本。对某一段点「重新抽卡」，用同样的提示词和参考图再出一条；所有版本都保留，并排预览，选一个作为「采用版本」。拼接时每段用它的采用版本。
  好处：能比较着挑，抽坏了也不丢原来的；代价：每抽一次付一次费，要新增版本记录。
- **B**：重新抽卡直接替换，旧的挪进备份目录，每段始终只有一个版本。
  好处：简单；代价：不能并排比较，想换回旧的得手动去备份目录找。

附带：只做视频（推荐，你说的是视频拼接），还是图片（资产图、交接板）也要能抽卡？

### 2. 回收保障做到什么程度

- **A（推荐）**：所有服务商统一。提交成功就把任务号记到这一段的记录里；轮询超时、网络中断、点停止、程序重启之后，重跑这一段时先续查旧任务，不重新提交。只有服务商明确回复失败，或者查不到这个任务，才重新提交。轮询超时不再触发自动重跑。
  好处：不会再为同一段重复付费，也不会丢已经跑完的成片；代价：要逐家核对查询接口（有的家任务结果只保留一段时间），工作量比较大。
- **B**：只止损。轮询超时和提交时网络中断改成「不自动重跑，停下来提示」，不做续查，旧任务需要你去服务商后台自己取。
  好处：改动小，马上不再重复付费；代价：回收还是靠人工。

### 3. 一家服务商挂了要不要自动换家

- **A**：不换（现状）。停在这一家，报出原因等你处理。
  好处：同一集用的是同一个模型，风格一致；代价：要人盯着。
- **B**：按设置里的优先级自动换下一家，补剩下的段。审核拦截、参数不合法这类换家也解决不了的错不换（和旧版规则一样）。
  好处：无人值守时能跑完；代价：同一集里可能混用不同模型，画风不一致，可能还得回头重抽。

### 4. 拼接时手动选择的范围

- **A（推荐）**：拼接前出一张本集清单，按剧本顺序列出每一段，每段选用哪个版本（默认是采用版本），也可以临时去掉某一段；顺序不能改。确认后拼接，原片保留。
  好处：配合抽卡刚好够用；代价：顺序调整、插入外部素材要到剪辑软件里做。
- **B**：在 A 的基础上还能调整顺序、插入外部视频。
  好处：简单的剪辑不用出程序；代价：等于在程序里做一个简易剪辑器，和第 4 步「剪辑」重叠。

**我建议的顺序**：先做 2（回收），因为它现在就在让同一段重复付费；然后做 1 和 4（抽卡和拼接清单）；3 看你的回答。

## 你的回答

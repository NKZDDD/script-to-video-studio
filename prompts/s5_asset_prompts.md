# 第五环节｜资产生产提示词

> **本次只处理 {{EPISODE}} 这一集。** 下面【待生产资产清单】里已经**只剩这一集新出现、
> 还没写过提示词的资产**——前面几集写过的不会再给你，别去操心它们。
> 资产提示词是全剧共用一份的（同一个角色只出一张图，跨集人脸才一致）。

为每个待生产资产输出一份**完整、独立、可直接复制**的图片生成提示词。

## 每份提示词必须包含
资产名称 / 输出结构 / 参考图角色映射（无参考图时省略）/ 身份绑定 / 外观与结构 / 材质 / 基础状态或剧情状态 / 允许改变内容 / 禁止改变内容 / 使用场景 / 输出限制

## 输出规格模板
- `four_view`（人物/生物）：一张竖版图 2行2列 四视图——左上正面全身、右上侧面全身、左下背面全身、右下正面半身特写；纯浅灰摄影棚背景、均匀柔光、站姿自然；四视图人物脸型发型服装体态完全一致
- `scene_wide`（场景）：空镜定场图，无人物
- `prop_multi`（道具）：正/侧/45° 三视图，纯色背景
- `closeup`（附属特征）：特写 + 位置示意
- `state_composite`（组合连续性锚点）：组合多个已经固定的来源资产，只锁定跨段持续的
  位置、姿势、距离、面向、接触、持有或阵型；不承担单个镜头的景别和运镜

## 强制收尾句
每份提示词末尾必须带：`超高清，细节清晰，避免手部畸形、多余手指、多余肢体、模糊面部。画面内不得出现任何文字、字母、数字、标注、水印。`

## 两种状态资产分别怎么写

- `state_type: single`：先复述唯一父资产的 `identity_anchors` 原文，再用单独的
  「状态差异」小节明确写出本图相对父资产必须发生的变化。禁止只复述父资产，
  也禁止写其他主体的位置和动作。
- `state_type: composite`：没有父资产。逐张复述 `reference_assets` 的身份绑定，
  明确每张控制谁/什么；正文只固定这些来源资产之间的关系，禁止重新设计任何来源资产。

## `reference_assets` 怎么填（这决定出图时喂哪几张参考图）

不是只能填父资产 —— 它是个列表，**画面里必然出现的已建资产都要列上**，
否则那部分只能靠模型现编，出来和别处对不上。

- 先复制待生产资产自身声明的 `reference_assets`，不得擅自删减。
- `single`：唯一父资产必须排第一；通常只需这一张。如果确实需要固定多个对象关系，
  说明它不该是single，应回到环节4拆成单体状态 + composite组合锚点。
- `composite`：没有父资产，列表至少两个；逐张保留全部来源资产。
- 可用ID以【可用参考资产目录】为准。
  例：手背特写搁在病床上 → `["C002", "ST008"]`（人 + 病房状态）。
- 只列**清单里真实存在**的 `asset_id`。写一个不存在的 ID，出图那一步会直接停。
- 在「参考图角色映射」里逐张写清**这张控制什么、不控制什么**，别复述外观。

## 输出结构与画面内容不一致时怎么办

拿到 `composite` 却声明 `scene_wide` 时，不要删除人物、也不要缩减参考图；本份提示词
必须改用 `state_composite`。只有标准环境资产或 `single` 环境状态明确写着
「空镜、无人物」时，`scene_wide` 才能保持空镜。

## 输出 schema

```json
{
  "asset_prompts": [
    {
      "asset_id": "C001",
      "filename": "C001_PROMPT.txt",
      "category": "identity",
      "state_type": "",
      "output_spec": "four_view",
      "size": "{{IMAGE_SIZE}}",
      "reference_assets": [],
      "prompt": "完整提示词正文，可直接复制投喂图片模型"
    }
  ]
}
```

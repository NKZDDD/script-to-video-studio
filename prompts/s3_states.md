# 第三环节｜状态时间线管理

> **本次只处理 {{EPISODE}} 这一集。** 下面给的输入都是这一集的，所有段落 id 必须是 `{{EPISODE}}-SEGnn`；
> 集号写错，后面的绑定、分镜、出图出片会全部对不上号。


状态时间线是整个系统的连续性核心。**上一段退出状态 = 下一段进入状态**（指客观状态一致，不要求画面构图相同）。

## 状态分类
- **人物**：健康/受伤/昏迷/苏醒/被控制/被释放/换装/衰老/觉醒/情绪改变/身份暴露/持有道具/失去道具
- **道具**：完整/开启/关闭/装满/空置/破碎/丢失/转移持有人/被没收/被消耗
- **场景**：白天/夜晚/雨天/雷暴/火灾/破坏前/破坏后/人群聚集/战斗后
- **生物与特殊元素**：完整/受伤/死亡/进化/能量增强/能量衰弱/形态切换

## 输出 schema

```json
{
  "timeline": [
    {
      "state_id": "ST001",
      "object": "对象名（人物/道具/场景/生物）",
      "parent_asset": "所属父资产的名称或 ID（如无填空）",
      "first_seg": "{{EPISODE}}-SEG01",
      "range": "持续范围，如 SEG01-SEG06 或 本集全程",
      "trigger": "触发事件",
      "entry_state": "",
      "exit_state": "",
      "irreversible": true,
      "dependent_segs": ["后续依赖该状态的段落"],
      "need_state_asset": true,
      "reason": "是否需要生产连续状态资产的理由"
    }
  ],
  "segment_states": [
    {
      "id": "{{EPISODE}}-SEG01",
      "entry": {"人物/道具/场景对象": "该对象在本段开始时的客观状态"},
      "persistent": ["跨段保留的状态"],
      "exit": {"对象": "本段结束后的客观状态"},
      "irreversible": ["本段产生的不可逆事实"],
      "temporary": ["本段内的临时表现：动作/表情/站位（永远不做成资产）"]
    }
  ],
  "continuity_check": [
    {"pair": "{{EPISODE}}-SEG01 → {{EPISODE}}-SEG02", "consistent": true, "note": "不一致时说明差异"}
  ],
  "axis_convention": {
    "axis": "本集主轴线怎么建立（沿哪条线、横向还是纵向），如「沿重症监护室玻璃门横向建立」",
    "left": "固定在画面左侧的人物或阵营",
    "right": "固定在画面右侧的人物或阵营",
    "depth": "后景/前景的固定归属，如「病床与玻璃门在后方」",
    "entries_exits": "主要人物的进出方向约定，如「Dewi 从右侧进入、向右离开」",
    "key_props": "重要道具的固定位置约定",
    "changes": [
      {"at": "{{EPISODE}}-SEG07", "note": "换场必须换轴时，在这里显式声明新轴线；不换就留空数组"}
    ]
  }
}
```

> `segment_states` 必须覆盖全部段落，且逐对校验相邻段的 exit/entry 一致性，结果写进 `continuity_check`。

## 轴线约定（整集一套，不是每段一套）

`axis_convention` 是**本集所有段落共用**的 180 度轴线与左右位置约定。第七环节各段
直接引用它排镜头，**不再各段自行决定左右**——否则同一个人这段在左、下段在右，
硬切就跳轴。

你是唯一能看到本集全部段落的环节，所以这件事必须在这里定一次：

- 左右归属一旦定下，全集不许翻转；确实要换场换轴的，写进 `changes` 显式声明
- 以主场景、主对抗关系定轴，不要以某一段的临时构图定轴
- 人物进出方向要和状态时间线的因果一致（谁离开、谁留下）

# 第九环节｜摄影镜头与剪辑时间

> **本次只处理 {{EPISODE}} 这一集。**

决定**怎么看**（镜头）和**怎么接**（转场与时长）。这两件事必须一起定 ——
分开定必然算出一个装不下的 SEG。

## 〇、两个秒数，别搞混

| | 这次是多少 | 谁决定的 |
|---|---|---|
| **本集总时长** | **{{EPISODE_DURATION}} 秒** | 剧情。第一环节看完全篇定的 |
| 单个 SEG 容器 | {{DURATION}} 秒 | 视频模型一次最多生成多久，是技术上限 |

**你要铺满的是本集总时长，不是一个容器。**
这一集预计装进 **{{SEGMENTS_TARGET}} 个** SEG（{{SEGMENTS_WHY}}），
装箱是第十环节的事，你不用管边界在哪。

> 本集总时长写着 0 时（老项目没存这个数），才退回按 {{DURATION}} 秒估。

**绝对不许把整集压进 {{DURATION}} 秒。** 这条犯过：
八个场次被压成 15 秒的「高密度因果蒙太奇」，每镜 0.9 秒，
第十环节于是只装出 1 个 SEG，往下全线崩 —— 故事板一张纸要画 16 格
（上限 9 格），模型记不住八个场次的世界状态，就把所有格子的
`source_scstate` 全填成第一个，道具状态和 CVS 互相打架。

发现装不下的时候，**不许压缩** —— 时间不够就是镜头数或动作设计要改，
或者本集时长本身要回上游改。压缩会让下游每一步都在错的前提上工作。

## 一、镜头数量不设区间

同样 15 秒，可以是 3 个情绪镜头，也可以是 8 到 12 个动作镜头。

**不要凑数，也不要按秒数除**。镜头数由这几样决定：这一拍有多少信息、
动作多复杂、表演节奏多快、空间关系需不需要交代、导演要强调什么。

每个镜头必须有**功能**：建立空间 / 揭示信息 / 承载动作 / 捕捉反应 /
改变权力关系 / 控制悬念。**没有功能的推拉摇移一律不要**。

## 二、镜头不许改世界

机位可以改变**观察的位置、景别、角度、构图**。

不许移动：门、窗、电梯、病床、墙体、道路地标，以及**人物真实所在的区域**。

每个镜头写 `camera_position_xyz` 和 `look_at_xyz`，用第五环节那套坐标。
需要一个第五环节没登记过的观察方向时，在 `new_view_needed` 里标出来 ——
**不要在这里第一次发明房间另一侧长什么样**。

### 画面左右是算出来的

`screen_direction` 是拿机位去投影 CVS 的坐标得到的结果。

切换机位后**重新算**，不要把「她永远在画面左边」写成物理真相。
她在 A 区坐标 [1.2, 3.0, 0]，机位换到另一侧时她自然就到画面右边了 ——
这是对的，不是跳轴。真正的跳轴是**坐标没变而画面关系乱了**。

## 三、转场：六类机制，不是只会硬切

**每个转场同时声明三层，缺一层都不行**：

```
机制（画面实际怎么变）
+ 剪辑语法（为什么这样接）
+ 执行模式 = MODEL_NATIVE_ONLY（模型在一次生成里做完）
```

只写「电影感转场」，或者把机制留给模型自己选，结果一定是退化成全片硬切。

### 先看这次能用哪几类（能力闸门）

{{CAPABILITY}}

**只能从上面列出的机制里选。** 没列出来的做不出来 —— 结果不是报错，
是转场糊掉，或者干脆变成一个长镜头，而任务标成功。

### 六类原生机制

| 机制 | 什么时候用 | 必须写清 |
|---|---|---|
| `NATIVE_CUT` | 同一动作/同一时空；动作匹配、视线匹配、反应切、强反差 | `cut_at` 精确切点 + **不许在两个机位之间做连续运镜** |
| `SHIELDED_OCCLUSION` | 跨地点、跨线程、跨状态 | 用什么遮挡、遮到 100% 的那一刻才切 |
| `MOTION_BRIDGE` | 情绪或因果连续但地点变了 | 运动方向、速度趋势，下一镜必须接住同一方向 |
| `OPTICAL_COVER` | 明确的时间跳跃 | 用黑场/白场/闪光/失焦，优先能把画面清空的 |
| `NATIVE_DISSOLVE` | 时间流逝、回忆、梦境、主观意识 | **禁止脸、身体、服装、伤口、道具、场景发生形变** |
| `VFX_THREAD_TRANSITION` | 镜面、水面、烟雾、能量这类 | 必须绑已批准的 VFX 和现实线程 |

### 稳定性从高到低

```
NATIVE_CUT > 完全遮挡 > 黑场/闪光/全失焦 > 甩镜 > 叠化 > 人物或场景形变
```

**最后一档默认禁止**，除非形变本身就是剧情事件。

选不准时**往上挑更稳的那一档** —— 一个干净的硬切永远好过一个糊掉的叠化。

### 转场数量也是动态的

每个转场必须有叙事、动作、声音、空间、时间或情绪上的功能。
**不许为了炫技加没有功能的转场。**

## 四、遮挡式转场的状态切换

跨地点、跨线程、跨外观状态时，优先建一个遮挡窗口：

```
只有起点状态 → 遮挡建立 → 100% 遮挡 → 【状态切换点】→ 遮挡解除 → 只有终点状态
```

- 完全遮挡之前**只允许起点状态**
- 达到 100% 遮挡之后才允许切换
- 遮挡解除之后**只允许终点状态**
- 遮挡期间不许出现混合的脸、混合的身体、混合的服装、混合的地点

**叠化时画面重叠 ≠ 两个状态同时存在。** 叠化中的光学重叠没有故事真相权力：
未来状态不能因为叠上去了就提前进入前一个镜头，已经生效的状态也不能
因为旧画面盖上来就被重置。

## 五、时长与节奏

**时间计划要铺满 {{EPISODE_DURATION}} 秒**（最后一个镜头的 `end` 就是这个数）。
不是 {{DURATION}} 秒 —— 那是一个容器的容量，见第〇章。

对白按**自然语速加表演停顿**估时，不要机械快进。
节奏靠信息密度、切换和表演控制，不靠把动作播快。

**转场要占真实时长**，必须写进时间计划里 —— 不能算在时长之外。
一次遮挡转场吃掉 1.2 秒，这 1.2 秒就是从本集总时长里出的。

`reaction_hold`（反应停顿）别省：第七环节写的反应延迟在这里变成秒数。

### 最短动作时间必须真的装得下

空间主表给了 `minimum_action_time`：下桌 1.2 秒、边看边走 8 秒、
推戒 4 秒并停住 2 秒 —— 这些是物理下限，**不是可以压的建议值**。

给一个动作的镜头时长少于它的最短动作时间，就是在要求模型
在做不到的时间里做完一件事。结果不会报错，只会做出个半截动作，
或者干脆变成一个静止画面。

装不下就改镜头设计（省掉这个动作、改成已完成的结果状态、
用硬切承接），**不要靠缩短时间硬塞**。

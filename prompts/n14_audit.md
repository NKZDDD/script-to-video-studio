# 第十四环节｜漏洞审计

> **本次只审 {{EPISODE}} 这一集。**

在花钱出图出片**之前**，把这一集的全部产物过一遍，找出会导致
「东西做出来了但是错的」的问题。

## 一、这一层只找一类问题

**不报错、只是错。** 跑完看着全成功，要到人工验收才发现脸不对、
片子短了一段、道具凭空多出来一个。

不要审美判断（那不是你的活），不要挑文笔。只查**结构性矛盾**。

每条发现给一个 `severity`：

| | 含义 | 该怎么办 |
|---|---|---|
| `BLOCK` | 这样跑下去必然出错 | 修完再跑 |
| `WARN` | 大概率出问题 | 人看一眼决定 |
| `NOTE` | 不影响执行，但值得知道 | 记下来 |

## 二、逐条检查

### 状态与时间

- [ ] 有没有第二套「当前世界状态」在和总账打架
- [ ] 每条状态有没有激活事件、持续规则、结束条件
- [ ] 已经生效的状态有没有在后面无缘无故消失
- [ ] 有没有未来状态提前出现（完整的、局部的、弱化的、模糊的都算）
- [ ] 动作完成之后有没有又重演一次（签字、跌倒、拔针、撕毁）
- [ ] 起因和它的关键结果是不是在同一段里

### CVS 与走位

- [ ] CVS 里有没有混进景别、机位、构图、画面左右
- [ ] 人物和关键道具有没有世界坐标；切镜有没有静默改变真实位置
- [ ] 走位在物理上做不做得到（服装/伤势限制、通路、手上占用）
- [ ] 相邻 SEG 的退出状态和进入状态接不接得上

### 资产与参考图

- [ ] 每条状态资产是不是只描述它父资产自己（有没有写进别的主体）
- [ ] 画面描述里出现的每个主体，是不是都在参考图列表里
- [ ] 参考图里有没有资产表里根本不存在的编号
- [ ] 有没有把「本段故事板」自己写进故事板的参考图（循环）
- [ ] 每张参考图的 `Image N` 编号和上传顺序对不对得上
- [ ] 四段权威（保留/改变/不许复制/不管）有没有写全，
      尤其是最常漏的 `MUST NOT COPY`
- [ ] 判了 `must` 的资产是不是都有生产提示词

### 道具

- [ ] 同款道具有没有分开外观规格和物理实例
- [ ] 存在总数对不对账（可见 + 部分 + 遮挡 + 画外 = 总数）
- [ ] 遮挡、离画、装进容器有没有被当成消失
- [ ] 持有人、归属、容器有没有混用

### 转场与 SEG

- [ ] 每个转场有没有写全机制、剪辑语法、执行模式
- [ ] 有没有转场被拆到两个 SEG 里
- [ ] 转场占的时间有没有算进 SEG 时长
- [ ] 遮挡式转场的状态切换点是不是在 100% 遮挡之后
- [ ] 模型能力不足时有没有降级到更稳的原生机制，
      而不是静默改用外部剪辑

### 故事板与视频

- [ ] 故事板有没有复制 SCSTATE 的中性机位（每格必须是新观察）
- [ ] 相邻两格的动作阶段有没有重复
- [ ] 有没有为了凑满格子而加重复的情绪格
- [ ] 每个视频窗口有没有做镜头显露包络和首次显露检查
- [ ] 未定义的区域有没有被允许显露
- [ ] 视频提示词有没有要求「一次输出完整成片」

### 强制故事板骨架与导演级执行（V6.2 第 19 章）

- [ ] **每个视频段落都有覆盖完整关键推进的故事板时间骨架** ——
      没有退化成只有一张起始图、只有 SCSTATE、只有 LOOK 或只有文字
- [ ] 骨架是有序的（有序连续 Sheet 或同一 SBPKG 的有序独立 KF 锚点），
      顺序没有乱、没有跨段混用
- [ ] 有没有哪个关键时间窗既没有 Sheet/KF 锚点覆盖，
      也没有合法理由标记为两个锚点之间的视频重建
- [ ] 每张骨架图过了准入：版本、SEG、Thread、时间范围、状态、位置、边界
- [ ] 有没有用正确的 LOOK / LOC_VIEW / 文字去「压过」一张错的故事板
- [ ] 每张补图都写得出独有权威贡献，没有和骨架争夺时间、动作阶段、走位或镜头顺序
- [ ] SCSTATE 有没有和表达同一状态的故事板一起上传（重复投票）
- [ ] 每个 Image 有完整 ID、是谁/是什么、当前状态、角色、
      控制什么、不控制什么、适用时间窗、准入结论
- [ ] 视频提示词达到导演级密度：时间窗、Beat 目的、微表演、动作阶段、
      物理反应、镜头语法、声音同步、窗口出口都明确 ——
      **没有用形容词堆砌代替可执行动作**
- [ ] 关键 Beat 的微表演是可拍的行为，不是「紧张」「悲伤」这类情绪词
- [ ] 高风险动作有完整阶段与物理结果；受动者没有在接触前就完整反应；
      道具没有在手闭合前换持有人
- [ ] 每个镜头有叙事功能、轴线、焦点、显露范围与切换动机
- [ ] 超载时按保护顺序简化镜头和装饰，
      没有删因果、位置、状态、声音或结果
- [ ] 逐窗重复了当前持续状态和关键位置，没有写「同上」「保持一致」

### 覆盖与切段

- [ ] 环节3 切出来的段，是不是每一段都编到了
- [ ] 有没有哪一段一张参考图都没有

## 三、输出要能直接照着改

每条发现写清：**在哪个产物的哪一项、具体是什么、会导致什么、怎么改**。

```
❌ 参考图有问题
✅ n12 的 SBPKG_EP01-SEG03 参考图第 2 张写的是 ST008，
   但 reference_order 第 2 位是 C005 —— 编号错位，
   模型会拿病房的图去沿用人脸。改成 Image 2 = C005 Nyonya Dewi。
```

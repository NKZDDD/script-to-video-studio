# 第二环节｜节奏驱动的段落划分

> **本次只处理 {{EPISODE}} 这一集。** 下面【本集剧本】里给的就是这一集的正文，
> 不要去想别的集。所有段落 id 必须写成 `{{EPISODE}}-SEG01`、`{{EPISODE}}-SEG02` ……
> 集号写错，后面的资产绑定、分镜、出图出片会全部对不上号。
>
> **本集必须切成 {{SEGMENTS_TARGET}} 段。** 这个数是环节1 看完全篇之后按这一集的
> 剧情事件数和体量定的（{{SEGMENTS_WHY}}），不是你来判断该切几段 ——
> 你只看得到这一集，判断不了它在全剧里该占多长。
> 段数不对，这一集的成片时长就和别的集不一致。

不按自然段、页数或对白数量机械切割。按以下信号确定段落边界：新目标出现 / 新威胁出现 / 重要信息揭示 / 关键道具出现 / 角色状态改变 / 人物关系改变 / 阵营立场改变 / 环境状态改变 / 剧情完成一次反转 / 出现适合作结尾钩子的状态。

## 划分要求
- 每段约 {{DURATION}} 秒，完成**一个明确剧情任务**（如：角色发现秘密 / 系统完成绑定 / 关键道具出现 / 人物遭遇危机 / 能力觉醒）。
- 段落开始能承接上一段，段落结尾能推动下一段。
- 不能把同一关键动作的原因和结果无意义拆开。
- 不能让段落结尾停在没有信息价值的位置。
- **段数必须正好 {{SEGMENTS_TARGET}} 段**，不多不少。这不是参考值。
  - 觉得剧情装不满 → 把描写细化成独立的叙事动作，不要合并段落。
  - 觉得剧情装不下 → 压缩单段内的过程描述，不要额外加段。
  - 确实完全放不下（比如这一集其实是两集被并在一起了），在
    `segments_note` 里写清楚，仍然按 {{SEGMENTS_TARGET}} 段输出 ——
    人会看到这条提醒并回去改环节1 的集边界。

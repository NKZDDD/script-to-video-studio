# Respect 字幕工作台

双击 `Respect-Subtitles.exe`。无需安装或启动 Studio，无需创建项目。

1. 添加视频或文件夹。视频可以来自 Studio，也可以来自其他软件。
2. 已有 SRT、ASS、VTT 时，选中一条视频，点“指定已有字幕”，即可跳过识别。
3. 选择输出目录；可以只导出字幕，也可以同时生成带字幕视频。
4. 在“识别与翻译”选择引擎与语言。纠错、翻译默认关闭；启用 LLM 纠错或翻译时填写接口、模型和 Key，Key 只在本次运行中保留。
5. 在“字幕样式”选择样式或导入自定义样式。hard 表示烧入画面，soft 表示可关闭的字幕轨；软字幕外观由播放器决定。四份中文/英文、横屏/竖屏样式已包含。
6. 点击“开始处理”，下方查看进度。可以停止，失败项会显示原因，其他视频继续处理。

原视频和导入字幕不会覆盖，每次输出一个新文件夹。可直接打开导出的字幕文件修改，再指定这份字幕重新合成。

bijian / jianying 识别需要联网；Whisper 类本地识别需要自行准备模型和对应运行条件，本发行包不预装大型模型。普通字幕合成只在本机运行，无需 Key。

独立设置保存在 `%LOCALAPPDATA%/Respect-Subtitles`。字幕引擎为 VideoCaptioner，视频处理使用 FFmpeg；相关组件保留各自许可证。

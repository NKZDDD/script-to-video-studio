# Agent 生产工作台

EXE 版：双击发布包中的 `Respect短剧制作平台.exe`（日期版文件名带日期后缀），浏览器会打开本机工作台，无需安装 Python。源码版：`py run.py`。已有运行进程需退出后重新启动才能加载更新。

服务商明确返回任务失败时，Studio 显示“失败”、保存失败原因并自动解除旧任务 ID，无需手动放弃。本批不会自动重新生成；修改参数后重新查看生产计划、开始生产，才会提交新任务。查询超时、网络中断、查询不到任务（包括 404）、下载或文件检查失败仍保留原 ID，继续取回；这类任务要主动重新生成时才需要手动放弃。旧版待取回记录也适用：再次查询确认失败后自动解除，不会仅凭旧日志里的“失败”文字丢弃记录。

升级时只替换程序，保留原有 `config.json`、`projects/` 和 `providers/`。启动窗口会显示实际读取的数据和项目目录；使用自定义数据目录的，继续沿用原来的 `--data` 参数。发布包不含个人密钥或项目。

1. 在“项目”搜索旧项目，或点“创建项目”。“归档”只是把项目从列表里藏起来，文件都不动；要找回，在“项目状态”里选“已归档”，点“恢复”。五步向导有默认值，确认生产父目录、原文、创作边界、模型方向与技能选项。
2. 创建后打开“Agent 契约”，复制完整模板交给 Agent。模板包含本机绝对路径。项目目录中的完整技能包和 `production-contract.md`、`production.schema.json`、`project-lock.json` 是执行依据。
3. Agent 将提示词和 `tasks.json` 写入新发布目录，最后原子写 `READY.json`。Studio 启动时及每隔 5 秒扫描，校验后接收；页面也支持立即刷新。不会因为材料就绪而自动发起付费生成。
4. 在“生产”查看、搜索筛选并勾选。树形分组有四种：按资源分类（父子）、按资源类型 → 集、按集 → 资源类型、按磁盘目录。每个文件夹后面写的是“已完成 a/b · 选中 c/b”：这一组共 b 条，其中 a 条已经有有效产物、c 条勾选了。新任务默认全选，选择自动保存；过滤只改变显示。点“补选依赖”可补齐必要上游，已有效的成品无需重新勾选或收费生成。
5. 填好“设置 → 服务商与密钥”，在生产页选择各类模型和批内并发，查看计划后开始。每一行的“比例”和视频那一行的“清晰度”“秒数”都是直接传给服务商的参数（清晰度写在模型名里的模型，比如鹤的 `…-720p`，显示“由模型决定”），下拉里是当前模型声明支持的档位；选“跟随任务”时用每条任务里写的值。图片行的比例按这一类（资产图、场景状态图等）统一覆盖，视频行覆盖画幅。改了秒数，提示词仍是按原秒数写的时间窗口。出来的图比例和请求的不一样时，这一条会挂“比例不对”的提醒，写明请求发的是什么、回来的是多少像素。任务会等待必要上游完成。失败可在明细查看，点资源的“交给 Agent 修订”生成定向修订文件。
6. “产物”按固定资产、连续状态资产、场景状态图、交接板、区域图、分段视频分组查看实际图片和视频，固定资产按人物身份、造型、场景等再分，分段视频按集再分。视频可以拖动进度条。核心运行状态与错误固定可见；更多功能入口在“设置 → 功能包与路径”开启。

右侧详情里的参考图按上传顺序显示缩略图和状态；点击已就绪的图片放大预览，关闭后保留当前任务和勾选。要跳转到参考图对应任务，点卡片下方“查看任务”；还没做好的会在上方列出任务名，也可点击跳转。任务明细里“说明”写着这一条在等哪个上游、还是在排队等并发名额，任务名可以点击跳转；“重试”一栏是这条已经重试了几次、最多几次。点明细窗口外面就能收起。

超模的两把图片 Key 按模型分组选择：“TH 分组 Key（原图片 1K）”填写 TH Key，“Native 原生 Key（原图片 4K）”填写原生 Key。TH 模型选 4K 仍用 TH Key，Native 模型选 1K 仍用原生 Key；清晰度独立通过 size 参数传给服务商。统一 TH / Native 模型支持 1K、2K、4K，`gpt-image-1k-th` 仅支持 1K。已安装过同类服务商外挂的，升级时按发布包内说明将旧外挂移出 providers 备份，避免覆盖新内置实现。

技术失败（网络抖动、服务商忙）自动重试的次数在“设置 → 并发与重试”里改（默认 2，不设上限），生产计划和任务明细里都会写出来。参数错误不重试。各类并发、全局和服务商并发也不设上限，至少为 1。

被服务商的内容审核拒绝时，可以让 LLM 改写提示词后重发：在“设置 → 提示词改写 LLM”填 Base URL、API Key、模型和改写轮数（默认 12 轮，填 0 关掉）。工作台里 LLM 只做这一件事，不做剧本分析，也不改没被拒的提示词。改写分四级（换措辞 → 弱化画面 → 调镜头 → 改事件的发生方式），每一版都会先检查：删了内容、动了“Image N = 谁”那几行的不会发出去。改写前后的全文记在项目的 `03_提示词/自动改写/`，任务上也会挂一条提醒。LLM 没配好时，被拒就照常报失败，生产计划里会写明。

点“开始生产”后，这一批勾选的任务会自动取消勾选：再点一次不会重复提交。失败了要重做，把状态筛选选“失败”，点“选中当前结果”再生产。重新抽卡也一样，开始后那一段就取消勾选。

同一个项目可以同时跑几批，只要任务不重叠：已经在另一批里生成的任务，这次不会重复提交；依赖它的会等它做好再开跑。

## 放入外部图片

生产树里一条显示“已完成”，只看它“输出”那一行写的路径上有没有一张完整的图：名字、扩展名、文件夹差一点都不算，放在别处也不认。“输出”写的是程序要找的位置，不代表那里已经有图。详情里出现“删除产物…”按钮，说明那个路径上有文件（哪怕是坏的）；没有这个按钮就是那里还没有文件。

从别处拿来的图有两种放法：

- 一张：在详情里点“手动放图 → 选择图片…”。
- 一批：生产页标题旁点“批量放图…”，选一个文件夹或多选图片。程序按文件名对应任务 —— 文件名和任务的输出文件名、任务 ID 或资源名称一样（或包含）就算对上，全角半角、大小写、空格和常见标点不算差别。先列出对应结果：几个任务一样像的不替你挑，对不上的可以输入任务 ID 手动选，已经有文件的任务不会覆盖。确认后点“放进去”。

两种放法都会按输出路径的格式转换（JPG 放进要 PNG 的任务会存成 PNG）并完整校验。Codex 在另一台电脑上时，它放进 `02_固定资产` 的图不会跟着发布包回来，需要把图拷过来再用这里放。

## 删除产物

在生产页右侧详情或产物页卡片上点“删除…”。删除的是已生成的文件：会挪进 `07_检查与记录/回收站/<时间>/`，保留原来的目录结构，旁边有一份 `删除清单.json`，想要回来就从那里拷回原位置。任务留在生产树上、变回待生产。

删除窗口里可以勾选连带范围，删之前会列出每个将被删的文件：

- 连同下游（子链路，默认勾上）：拿它当参考做出来的，一直往下。它们是用旧图做出来的，旧图没了就对不上。
- 连同上游（父链路）：它用到的参考图，一直往上。
- 连同兄弟链路：和它共用同一个上游的其他任务。

勾了下游时，列表里每一项的下游都会一起删。正在生成的任务不能删，先停止那一批或等它结束。

运行状态显示在标题栏中，点击可展开 CPU、内存等详情。生产页最上方的按钮栏提供“查看生产计划”和“开始生产”，滚动时固定在标题栏下方；计划详情显示在按钮栏下面的正文里，不跟着滚动，长计划在计划区域内部滚动。资源树与详情在各自区域内滚动，点击父标题展开或收起，父标题前的勾选框只改变选择。每页右下角都有“回到顶部”，生产页还会同时将列表、详情和计划滚回顶部。自动刷新保留目录展开、图片预览、产物筛选及滚动位置；材料、勾选或参数变化后须重新查看生产计划。

已经提交给服务商、结果还没取回的任务（排队久了超时、点了停止、程序重启），左侧树会显示“已提交待取回”。下次生产会先续查原任务，不重新提交、不重新付费；生产计划里会写明有几项。只有服务商回复失败、或者查不到这个任务时，才会重新提交；提示词、参考图、参数或服务商/模型改过，也会重新提交，日志里会说明原因。确定服务商那边已经查不到、或者已经从后台手动取回的，可以在右侧详情点“放弃这个任务，下次重新提交”。

提交请求发出去了、却没收到服务商的回复（读超时、连接中途断开、网关 5xx）时，服务商那边可能已经建好任务、开始计费，所以程序不会自动重发，这一段会报“提交后没收到服务商的回复，可能已经在计费”。请到服务商后台按提交时间核对：已经生成的，下载下来放到输出位置；确认没有生成的，再重跑这一段。请求根本没发出去（连不上、域名解析失败）和限流（429）照常自动重试。

分段视频不满意时，在右侧详情或产物页点“重新抽卡”：现在这条会移到 `05_分段视频/_抽卡备份/`，然后马上用同样的提示词和参考图重新生成（会重新计费），不用再点“开始生产”。别的批次还在跑也不用等，只等这一段自己的参考图。这一段因为缺上游、模型不支持等原因开不了跑时，原视频会放回原处，并提示原因。

开启“字幕与后期”后，“合成成片”会打开清单：勾几集就每集各出一个成片（例如勾 EP03、EP04 得到 `EP03_MASTER_…mp4` 和 `EP04_MASTER_…mp4`），点“全集”就是每一集各出一个。清单按集、集内按剧本顺序列出每一段，取消勾选就不拼这一段，↑ ↓ 调整顺序，还可以插入抽卡备份里的旧版本或外部视频（上传 40MB 以内的，或者把文件复制到 `06_成片/插入素材/` 后点“刷新清单”）；插入的视频归到它上面最近那一段所在的集，勾了几集时每行前面标着它归哪一集。改选集会重新列清单。每一集的画面按分段原片拼接，不重新压缩；每段的声音裁或补到这一段画面的长度再接，保证每一段的声音都从它自己的画面开始（AI 出的分段音轨常比画面长一点或短一点、采样率也各家不一，直接首尾相接会一路音画错位）。和本集分段分辨率或编码不同的外部视频只单独适配那一段，分段本身不重编码；分段之间规格不同会停下来说明，不把已经生成的画面压一遍。点“开始合成”后窗口马上关掉，合成在后台逐集跑，期间可以接着生产、放图或做别的事：进度在生产页的批次列表和右上角“任务总览”里（显示为“合成成片”），每合完一集，“任务明细”里那一行就有“打开”链接；中途可以点“停止”，正在合成的那一集会立刻停下、不留半成品。全部合完时页面会提示几集合好、几集失败。同一集正在合成时不能再开一次。用到的清单会另存为成片旁边的同名 `.json`。外部剪辑完的成片放进 `06_成片/`，就能在“字幕识别与烧录”里选到。也可识别字幕或复用同名 SRT，再生成带字幕的新成片。文字纠错和翻译交给 Agent；工作台字幕路径关闭文字模型调用，保留原视频。任务可从生产页查看进度和停止。

## Codex 不在这台机器上

在“Agent 契约”页的“Codex 不在这台机器上”一栏：

1. 点“导出交接包”，得到一个 zip。里面直接有 `剧本.txt`（全文）、`生产材料契约.md`、项目里已经有的分析文件和完整技能。把这一个文件交给 Codex 即可，不用再另附剧本。原文为空时不能导出。
2. Codex 可以按契约交回一个 `.jsonl`，也可以交回带 `READY.json` 的发布目录 zip。
3. 点“导入材料或发布包…”。`.jsonl` 按旧版生产材料导入，并立刻出现在生产页；`.zip` 仍走发布校验。不合契约的 jsonl 整份不导入，并给出可交回 Codex 的重产清单。

## 直接编辑任务提示词

在“生产”点选资源树中的任务，打开“查看 / 编辑提示词”，修改后点“保存新版本”。资产图、场景状态图、交接板整板、交接板区域图、分段视频以及旧项目任务均可编辑。保存前可展开查看受影响的任务。

保存会为本任务及实际引用它的下游任务分配新输出文件名，并同步更新文件引用，避免修改后继续复用旧成品。原提示词和旧产物保留；无关任务和原来的勾选状态不变。已经启动的批次继续使用启动时的快照，下次查看生产计划并开始时使用新版本。仅保存不会自动生成或调用服务商。

Agent 项目会生成下一份 `03_提示词/releases/rNNNN` 发布，后续 Agent 修订须以最新接收版为基准。旧项目更新任务清单并保留修改前记录。修改记录位于 `07_检查与记录/prompt-edits/`。没有实际修改时不创建版本；提示词不能为空。编辑期间若已有其他修改或新发布，保存会被阻止且保留输入内容，请复制内容后重新打开、对比再保存。

## 保存与兼容

- 默认项目位置可在“设置 → 功能包与路径 → 默认生产目录”修改并保存。新建项目自动填入新目录；创建向导中临时修改只影响该次创建。已有项目不搬动，原目录继续登记并显示在项目列表。
- 沧元算力分别提供图像和视频入口；全能力 Key 可在两处分别填写。2026-10-13 目录接入 32 个图像、34 个视频型号，按型号展示比例、清晰度、时长和参考数量；参考素材要求 HTTPS 链接，需要配置对象存储。目录可见不代表上游此时生成一定成功。
- 原服务商凭据与数据路径继续沿用。空密钥表示不改，服务端不回显已有密钥。
- 新服务商可以在“设置 → 服务商与密钥”点“导入服务商文件…”选中 `.py` 导入，也可以照旧放进数据目录的 `providers`。同名文件会先备份；新文件加载失败时自动恢复原样。
- 新项目含完整技能快照。更新工作台不会替换已创建项目锁定的技能。
- 新计划内容改变时须更换输出文件名，避免旧产物被误复用。已运行批次的任务和提示词快照保存在 `07_检查与记录/jobs/`。
- 旧项目继续读取其原来的任务和文件，包含旧项目已有的故事板；新项目不创建旧故事板任务。
- 资源“已完成”表示文件校验通过，画面、人物连续性、声音仍需人工验收。
- 生产上限由批内、服务商、全局共同约束，跨项目共享。实际线程数不是生产并发数；建议值没有足够样本时显示待采样。
- 服务商能力不兼容会在预览中报错；在生产页更换模型，或开启高级参数进行显式覆盖，或让 Agent 重新规划，不能静默降低规格。

# Agent 生产工作台

启动：`py run.py`，浏览器打开启动日志里的本机地址。已有运行进程需退出后重新启动才能加载本次代码。

1. 在“项目”搜索旧项目，或点“创建项目”。五步向导有默认值，确认生产父目录、原文、创作边界、模型方向与技能选项。
2. 创建后打开“Agent 契约”，复制完整模板交给 Agent。模板包含本机绝对路径。项目目录中的完整技能包和 `production-contract.md`、`production.schema.json`、`project-lock.json` 是执行依据。
3. Agent 将提示词和 `tasks.json` 写入新发布目录，最后原子写 `READY.json`。Studio 启动时及每隔 5 秒扫描，校验后接收；页面也支持立即刷新。不会因为材料就绪而自动发起付费生成。
4. 在“生产”按人物/资源树、集或磁盘目录查看，搜索筛选并勾选。新任务默认全选，选择自动保存；过滤只改变显示。点“补选依赖”可补齐必要上游，已有效的成品无需重新勾选或收费生成。
5. 填好“设置 → 服务商与密钥”，在生产页选择各类模型和批内并发，查看计划后开始。任务会等待必要上游完成。失败可在明细查看，点资源的“交给 Agent 修订”生成定向修订文件。
6. “产物”查看实际图片和视频。核心运行状态与错误固定可见；更多功能入口在“设置 → 功能包与路径”开启。

开启“字幕与后期”后，可按集顺序合成成片，也可识别字幕或复用同名 SRT，再生成带字幕的新成片。文字纠错和翻译交给 Agent；工作台字幕路径关闭文字模型调用，保留原视频。任务可从生产页查看进度和停止。

## 保存与兼容

- 原服务商凭据与数据路径继续沿用。空密钥表示不改，服务端不回显已有密钥。
- 新项目含完整技能快照。更新工作台不会替换已创建项目锁定的技能。
- 新计划内容改变时须更换输出文件名，避免旧产物被误复用。已运行批次的任务和提示词快照保存在 `07_检查与记录/jobs/`。
- 旧项目继续读取其原来的任务和文件，包含旧项目已有的故事板；新项目不创建旧故事板任务。
- 资源“已完成”表示文件校验通过，画面、人物连续性、声音仍需人工验收。
- 生产上限由批内、服务商、全局共同约束，跨项目共享。实际线程数不是生产并发数；建议值没有足够样本时显示待采样。
- 服务商能力不兼容会在预览中报错；在生产页更换模型，或开启高级参数进行显式覆盖，或让 Agent 重新规划，不能静默降低规格。

## 开发验证

新增契约与调度测试：`py -m pytest tests/test_agent_workspace.py`。
离线浏览器验收：`py tools/qa_agent_workspace.py`；使用独立测试配置及模拟生成，证据写入 `outputs/agent-ui-qa/`。
发布前须运行全量 `py -m pytest`。打包脚本已加入完整生产技能资源。

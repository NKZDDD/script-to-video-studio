# XMD 视频服务商

接口地址：`https://ai.xmdomain.dpdns.org`。依据用户于 2026-09-18 提供的《视频生成 API 接入说明》。界面名称按域名标为「XMD 视频」。

## 安装到现有 exe

1. 解压 `XMD-服务商插件.zip`。
2. Studio 设置页 → 插件 → **打开插件目录**。使用页面给出的数据目录，不要猜 exe 所在目录。
3. 将压缩包 `providers` 文件夹里的 **xmd.py** 放进这个插件目录。
4. 点 **重新扫描插件**，或重启 Studio。服务商列表应出现「XMD 视频」。
5. 在该服务商的 **API Key** 输入框填写一整行：

   ```text
   api_key=你的Key;api_secret=你的Secret
   ```

   两项都要填；分隔符是英文分号。保存后点「测试连通性」，通过时显示剩余次数。此测试只读取账户信息，不生成视频、不消耗生成次数。
6. 出片优先级中选 XMD，模型选 `seedance_2.5`，项目分段视频时长设为 **30 秒**。已有 15 秒分段不会被程序悄悄拉长，应先调整分段计划和提示词，再提交。

本次插件已在 2026-09-18 提供的 `0fe3a3b` 版 Windows exe 内验证加载和本机模拟接口全流程。源码也已加入内置服务商清单，后续重新打包会直接带上它。插件安装不会修改其他服务商配置。

## 图片大小

- JPEG、PNG、WebP，单张最多 **10,000,000 字节**，最多 10 张。文档没有区分 MB/MiB，采用较小上限。
- 合规图片按原始字节上传，不重编码、不缩尺寸。
- 超限图片先重编码压缩；仍超限才按比例缩小，直到上传副本满足上限。JPEG/WebP 可能降低画质；PNG 保留透明度。日志会说明大小和尺寸变化。
- 本地原图不会被覆盖；处理只用于这次上传。本机文件、Base64 图片和公网图片都经过相同检查，公网图会读取后上传到服务商。
- 此规则只作用于 XMD 出片参考图。其他服务商仍按原来的规则处理。

## 接口约束

- 只支持视频，不提供图片生成。
- 模型：`seedance_2.5`；时长：30 秒；比例：`1:1 / 3:4 / 4:3 / 9:16 / 16:9 / 21:9`。
- 提示词最多 3000 字符；超长、超图数、错误时长在提交生成前直接说明原因，不截断提示词或丢掉参考图。
- 固定模型没有模型列表接口，不需要「拉取最新模型」。旧 exe 点刷新可能提示拉取失败，已声明的固定模型仍可使用；应通过「测试连通性」核对凭据。
- API Key 和 Secret 在本地后端用于 HMAC 签名，不回传到页面，也不发送给素材或成片下载地址。
- 单次提交内的网络重试复用 `client_job_id`，每次请求生成新 nonce。查询临时失败继续查同一个 `job_id`。成功后立刻下载临时视频地址，下载失败只重取原地址。
- 如提交回执未取得或轮询到达上限，日志保留订单号或任务号。先让服务商核对原单，不要立即手动重跑。文档未提供按订单号查询接口，因此目前不能自动从未知回执恢复。

## 真人图库及可选参数

普通图片上传适用于文档所述产品、场景、动物、插画、已风格化人物。真人照片需要在**服务商网页图库完成过审**，再以 `gallery_ids` 提交。普通图片上传入口不会自动办理过审，也不会自动选择账户中的人物。

适配器支持 `VideoTask.extra` 中的 `gallery_ids` 和 `shield` 参数，并校验图库编号与普通图片合计最多 10 张；Studio 现有生产页面尚没有图库选择及视频盾开关，常规界面提交使用普通模式。此次未新增图库管理页面。

## 验证范围

全量离线测试：**2463 passed**，包含新增 49 项 XMD 测试。覆盖精确 JSON 签名、multipart 空 body 签名、nonce、幂等请求体、限流等待、真实超过 10MB 的透明 PNG、原图不变、JPEG/WebP 压缩、图片次序、参数拒绝、结果下载失败不重新生成。

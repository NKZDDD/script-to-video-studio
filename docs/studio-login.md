# Studio 登录使用说明

认证域名：`https://login.respect.chat`。此改动需要重新打包 Studio 才会进入 EXE；已发布的旧 EXE 不会自动增加登录。

启动后先输入管理员开通的账号密码。服务商 Key、模型配置、项目和素材仍在本机，生成请求由客户端直接发给服务商。登录服务只接收账号密码、随机设备标识和登录凭证。

## 校验行为

- 页面打开后先检查登录；未登录不能读取项目、文件或调用生产接口。
- 页面打开且登录有效时，每 60 秒在线校验。其他本机接口最多缓存 60 秒校验结果；开始新生产、合成、字幕处理、刷新模型前强制在线校验。
- 账号到期、停用或会话撤销后，下次校验锁定页面，须重新登录。后台停用不能撤销已经向服务商提交的请求。
- 认证服务暂时断网时锁定页面，点击“重新检查连接”重试；短暂失败至少间隔 5 秒再请求。保留有效会话，不把网络问题提示成密码错误。
- **已启动的整个批次继续执行和取回**，不会因为退出登录、认证断网或账号停用而中途取消。再次点击开始生产时需要有效在线登录。本版不在每张图/每个视频提交前单独校验。
- 已提交任务的 ID、结果及失败处理沿用原有规则，登录模块不清理、不重新生成。

## 凭证与设备

云端访问凭证和续期凭证只在本地 Python 进程内存里保存。浏览器只持有独立的 HttpOnly 会话 Cookie，不把云端凭证存入 localStorage 或 config.json。关闭 EXE 后需要重新登录；只刷新页面不需要。

数据目录中的 `studio-device.json` 仅包含随机设备 ID。通过页面迁移数据目录时会一同复制；自行迁移时请保留它，否则会被服务端视为新的安装。它不是不可伪造的硬件标识。

多线程请求串行续期，避免同时使用旧续期凭证。续期网络超时可能已在服务端完成轮换，因此不重试旧凭证，页面要求重新登录。

右上角账号按钮用于退出。退出会先清除本机内存凭证，再通知服务器；服务器离线不影响本机退出。

## 管理与部署

账号创建、有效期、停用及重置密码使用 [服务端管理说明](../auth_service/README.md) 中的终端命令。没有默认账号或自动注册入口。

宝塔反向代理目标为 `http://127.0.0.1:8781`，必须传递 `X-Forwarded-Proto $scheme`，否则外部 HTTPS 到达应用时会被当成 HTTP 并返回 `https_required`。健康检查成功不足以证明认证接口配置正确。

本机页面只接受 localhost/127.0.0.1 的 Host 和同源请求。客户端源码及服务商调用仍在用户电脑上，具备修改程序能力的人可以绕过本地授权；本方案用于正常客户端账号管理。

# Studio 独立窗口安装版

首次使用：关闭旧 EXE，运行 `Respect-Studio-Setup-2026.10.22.4.exe`，选择安装目录。可选择 D 盘；无需安装 Python。安装完成后从桌面或开始菜单启动 Respect Studio。

Studio 在独立窗口显示原工作台，不打开控制台或外部浏览器。保留图片、视频生产、成片合成和服务商接入；移除内置字幕识别、翻译、样式和烧录功能。已有字幕文件不会删除。没有捆绑整套 Chromium，使用系统 WebView2；缺少时安装器会联网安装微软运行库。

## 旧配置与项目

默认继续读取 `%LOCALAPPDATA%\Respect-Studio` 和已有数据目录指针。旧项目不用重新创建。

2026.10.22.4 安装版的「设置 → 服务商」只显示后台分配的名称和可用模型，可刷新配置与模型。接口地址、Key 和适配器由后台管理，不提供个人备用服务商配置入口；旧配置文件保留，但未获后台授权的服务商不会使用其中的个人 Key。页面接口也不返回适配器默认地址或凭据表单。当前任务仍由客户端直连服务商；彻底不向客户端交付上游地址和 Key，需要后续服务端中转，不能把页面隐藏等同于中转隔离。

如果旧配置放在旧 EXE 旁边，先在旧版「设置 → 功能包与路径」把程序数据迁出，再安装新版。安装目录只放程序，不要把项目或 Key 配置放入 `_internal`。卸载保留数据和项目。

## 更新

从 2026.10.22.3 起，桌面版启动检查发现新版本后会自动下载并校验，也可以在「设置 → 软件更新」主动检查。进度条满且显示“更新已准备好”后，点击「重启完成更新」即可：旧进程退出后，在原目录静默更新，再自动打开 Studio。不再显示目录选择、下一步等安装向导。

下载阶段可继续生产；重启前必须等待所有任务完成，包括已停止但仍在收尾的任务。程序不会自行强制退出。SHA256 或文件大小不一致的安装包不会执行。下载失败会显示原因，点击「重试下载」重试；强制更新也显示具体下载错误。

2026.10.22.2 及更早的客户端首次升级仍使用旧安装向导。这次安装好 2026.10.22.3 后，后续更新才使用新的重启流程。首次安装和手动双击安装包仍保留向导。

更新依赖管理员在登录后台发布新版本。现有 1.8.1 服务端可直接使用；上传 R2 后导入 `release.r2.json`，选择测试登记或推荐/强制发布，见 [后台升级说明](../auth_service/CLIENT-UPDATE-UPGRADE.md)。单独上传文件不会自动修改在线更新策略。

仍然下载完整安装包，配置、数据目录和项目保留。安装器只替换所带程序文件，不删除项目。重启会沿用当前数据目录，包括通过 `--data` 临时指定的目录。

## 排错

- 启动日志：当前数据目录 `logs/desktop.log`，最多保留当前文件和两份轮转日志。
- 窗口缓存：当前数据目录 `webview/`。
- 已下载的安装包：当前数据目录 `updates/`。
- 旧进程 60 秒内未退出，更新会停止并提示关闭程序后重试，不会强行终止任务。若文件被占用或安装失败，请关闭 Studio 后手动运行已下载的安装包修复；不承诺安装中断时自动回滚程序文件。
- 生产中点击窗口关闭会提示先结束批次，避免直接断掉生产进程。
- `Respect-Studio-CLI.exe` 是诊断辅助程序，平时从快捷方式启动主程序即可。
- 安装包没有附数字签名证书，Windows 可能显示未知发布者。

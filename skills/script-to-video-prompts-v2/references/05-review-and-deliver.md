# 环节 11｜结果检查与定向修订

检查的是**实际生成的视频**，不是重新检查提示词。这是人工环节。

## 八层检查

```
第一层：文件技术状态       第五层：动作因果
第二层：单段剧情完整性     第六层：空间轴线
第三层：人物身份一致性     第七层：段落进入与退出状态
第四层：状态连续性         第八层：跨段衔接
```

对照物：第三层对 `identity_anchors`；第四层对状态时间线的不可逆事实；第六层对环节 7 的轴线约定；第八层对 `next_anchor`。另需对照 `forbidden_future` 检查是否提前出现后续剧情。

## 视频固定标准

满足即固定：

```
核心剧情事件完整      人物身份基本稳定      关键动作因果清楚
进入状态和退出状态正确  关键道具状态正确      没有提前生成后续剧情
能够与前后 SEG 直接拼接  不存在严重技术损坏
```

**不要求**：所有背景群众面孔完全固定、每条电弧完全一致、每只道具位置完全一致、每个镜头达到审美上限、每句群体对白精确逐人口型。

## 问题三级

### 一级｜可接受偏差 → **直接通过并固定**

```
背景人物少量变化    非核心衣服褶皱变化    普通尘土或特效形态变化
背景人数轻微变化    不影响剧情的摄影机偏移
```

### 二级｜可定向修订 → **保留故事板，建视频提示词 V02**

```
某个镜头节奏过慢    一个动作方向错误    道具短暂消失
局部口型错误        人物短暂变脸        特效遮挡人物
```

修订格式——不重新拆分提示词，仍输出一份完整视频提示词，开头加：

```
本次修订目标：
只修正 {X.X}—{Y.Y} 秒 {对象} 的 {问题}。
保持 0.0—{X.X} 秒及 {Y.Y}—{结束} 秒的剧情、人物、场景、动作顺序和连续状态不变。
{对象} 应 {正确表现}。
{对象} 不能 {禁止表现}。
```

结果存为新版本，**旧版保留不覆盖**。

### 三级｜结构性错误 → **当前版本不固定**

```
核心人物身份错误    关键剧情节点缺失    动作因果改变
不可逆状态被恢复    退出状态错误        提前出现后续剧情
```

处理逻辑（沿依赖链回溯，改哪层重做哪层）：

```
故事板正确 → 修订视频提示词，重新生成视频
故事板错误 → 返回环节 9 生成故事板 V02
资产错误   → 返回环节 5 修改父资产或状态资产
             → 查资产使用索引找到全部关联段
             → 人工圈定重做范围（禁止一个错误导致整集重做）
```

每次修订在 `03_提示词/定向修订提示词/` 与 `07_检查与记录/` 各落一条：改了什么、为什么、重做了哪些文件、新版本号。

# 环节 12｜排序、拼接与交付

## 输入

只使用已标记为**固定**的视频版本，每段取最新固定版本。

## 拼接前处理

```
统一分辨率    统一帧率      统一编码      统一音频采样率
清除错误旋转信息            删除平台黑帧
删除无意义冻结帧            删除跨段重复静止帧
```

## 拼接方式

按 `episode_order` → `segment_order` 两级排序（读注册表，不依赖文件名字典序），**硬切直连**。

不得加入：淡入淡出、交叉溶解、白闪、旋转转场、缩放转场、形变转场。

执行清单（ffmpeg concat 格式）：

```
file '../05_分段视频/PROJECT-001_EP01_SEG01_VIDEO_V01_FIXED.mp4'
file '../05_分段视频/PROJECT-001_EP01_SEG02_VIDEO_V01_FIXED.mp4'
```

```bash
ffmpeg -f concat -safe 0 -i EP01_concat.txt -c copy PROJECT-001_EP01_MASTER_V01_FIXED.mp4
```

`-c copy` 流拷贝优先；编码参数不一致导致失败再退回重编码。

## 最终检查

```
段落顺序是否正确    是否漏段          是否重复段落
是否误用旧版或废弃版  剧情链条是否完整   跨段声音是否被截断
结尾是否停在正确剧情边界              是否提前进入下一集
```

## 交付包

```
00_项目说明/  01_剧本与分段/  02_固定资产/  03_提示词/
04_故事板/    05_分段视频/    06_成片/      07_检查与记录/
```

补一份**资产使用索引** `02_固定资产/asset_usage_index.json`：每个 asset_id → 使用它的 segment_id 列表。这是「改资产要重做哪些段」的唯一依据。

`07_检查与记录/` 应含：资产生产记录、故事板生成记录、视频生成记录、单段检查记录、跨段连续性检查、最终交付清单。

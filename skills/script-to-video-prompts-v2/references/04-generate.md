# 环节 9-10：故事板生成与固定 → 视频执行生成

**执行器无关**：消费环节 8 的 `tasks.json` + 提示词 + 固定资产/故事板；产出约定路径文件 + 注册表登记。
本仓库已有实现：`production_runner/`（本地 Web 程序，服务商可插拔、多线程、进度可视）。

---

# 环节 9｜故事板生成与固定

## 单次任务组成

```
一个 SEG 故事板任务
= 该 SEG 需要的参考图（按环节 8 的上传顺序）
+ 该 SEG 完整故事板提示词（原文复制）
+ 一次图片模型生成任务
```

不同 SEG 不能混在同一次生成任务中。

## 输出规格

```
一张完整故事板
4—6 个独立关键帧
关键帧按剧情时间顺序排列
每格竖构图，格左上角标注镜头编号
```

一次生成一张完整故事板；**不允许分别生成多张单格图再临时拼接**。

## 执行五步

1. 每个 SEG 单独开一次生成任务（不要把整集参考图塞进同一上下文）
2. 按环节 8 的上传顺序逐张上传，**上传后逐张核对**：实际第 N 张 = 提示词中的 Image N
3. 原文复制该 SEG 的完整故事板提示词——**不要另加**通用人物/场景/负面/镜头/参考图说明提示词（已包含在内）
4. 生成
5. 技术检查

## 技术检查（客观项，可自动）

```
是否成功生成          关键帧数量是否正确    阅读顺序是否正确
人物身份是否混合      是否缺少核心剧情节点   是否出现严重肢体错误
是否提前生成后续剧情   是否出现错误连续状态
```

**不做自动审美评分。** 构图不完美、表情不理想、光线不喜欢、褶皱有差异 → 不触发重做，进环节 11 人工分支。

## 固定原则

| 情况 | 处理 |
| --- | --- |
| 通过技术和剧情检查 | 立即固定 |
| 轻微审美问题 | 不自动重做 |
| 严重结构错误 | **只重做当前 SEG** |
| 技术失败 | 相同输入自动重试，**最多 2 次** |

## 生成顺序与跨段核对

按剧情顺序 SEG01→SEGnn 生产。原因：后一段的进入状态需要核对**前一段已固定故事板**的退出状态。每固定一张做一次配对核对。

（数据上段间无依赖，可并行提速，但会失去逐段核对的机会——按项目风险取舍。）

## 其他失败处理

| 情况 | 处理 |
| --- | --- |
| 参考图上传顺序错误 | 弃用输出，按正确顺序重传重生成（错误输出不得固定） |
| 缺格 | 修改输出结构指令，重生成，不进视频生产 |
| 人物身份明显混合 | 查 REFERENCE ROLE MAP → 减少无关参考图 → 强化唯一身份绑定 → 只重做受影响 SEG |
| 连续状态错误 | 查连续状态参考图是否正确上传 → 强化进入/退出状态描述 → 重做受影响 SEG，必要时同步重做后续依赖段 |

# 环节 10｜视频执行生成

## 环节定位（原文）

```
本环节不进行剧情分析。
本环节不重新生成分镜。
本环节不重新编写视频提示词。
本环节不修改人物、场景、道具和状态设定。
本环节只负责调用已经生产完成的内容生成视频。
```

一切检查规则、连续性要求、禁止内容都已写在环节 8 的提示词里——在执行环节重复它们属于流程冗余。

## 一段一条视频原则

```
一个 15 秒段落 = 一张固定故事板 + 一份完整视频提示词 + 一次生成任务 + 一条固定视频
```

不得把一个 SEG 拆成多条，不得把多个 SEG 合成一条。

## 执行动作

```
01 读取当前 SEG 固定故事板
02 读取当前 SEG 固定视频提示词
03 故事板作为视觉参考上传
04 提示词原文提交
05 设置目标时长、画幅（字幕关闭、水印关闭）
06 执行生成
07 下载并保存结果 + 写生成记录
```

**不在本环节增加新的提示内容。** 平台不能精确设时长时用最接近规格，拼接阶段统一裁切，不改剧情顺序。

## 结果处理

| 结果 | 处理 |
| --- | --- |
| 技术生成成功 | 进入环节 11 |
| 技术失败（报错/中断/损坏/打不开/时长为0） | 原故事板+原提示词不变，重新提交，**自动重试最多 2 次** |
| 内容存在问题（变脸/动作错/状态错/缺镜头/提前剧透） | **本环节不自动修改**——记录问题，交环节 11 |

## 审核适配（两环节通用）

平台审核拦截时**不改变剧情事实**，逐级降敏：

1. **忠实制作**——用原提示词
2. **镜头降敏**——`动作准备 → 直接硬切 → 动作结果`，保留施动者/动作对象/动作事实/动作结果/剧情因果
3. **结果叙事**——施动者准备动作 + 相关人物反应 + 动作结果已发生

**不能改成**：动作对象自行倒地、事故自然发生、施动者身份消失、动作因果不明确。

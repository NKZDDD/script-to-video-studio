# 环节 1-3：整剧全局解析 → 段落划分 → 状态时间线

产物落 `01_剧本与分段/`。

---

# 环节 1｜整剧全局解析

先理解整部剧本，再处理单集和单段，**防止局部优化破坏后续剧情**。第 8 集才砸毁的房间、第 3 集才揭晓的疤痕，都必须在这一步进入演化图，否则资产库中途返工。

## 必须提取

故事类型 / 世界观 / 时代背景 / 力量体系 / 主要矛盾 / 故事主线 / 主要人物 / 人物关系 / 人物目标 / 人物阵营 / 角色成长线 / 核心道具 / 关键场景 / 重要伏笔 / **不可删除事件** / **不可改变结果** / 每集剧情范围 / 每集进入状态 / 每集退出状态

## 输出结构

```
项目名称：      故事类型：      视觉风格：（用项目参数指定值，未指定才据剧本判断）
世界观：        力量规则：      核心主线：
主要人物：      主要阵营：      关键资产：
主要剧情阶段：  不可更改剧情事实：            需要长期维护的连续状态：
```

**人物 appearance 与场景 description 会被环节 8 直接复制进图片提示词**，必须写死稳定特征：年龄、国籍/人种、脸型、肤色、五官逐项、发型发色发质、身材、服装（款式+颜色+材质+细节）、气质。

## 视觉风格

作为**输入参数**优先采用；未提供时才据剧本判断。产出一行**压缩版**供后续提示词的【全局风格】直接引用。同一剧存在刻意对立的视觉线（如底层线 vs 顶层线）时，给多个压缩版变体并标注适用段落范围。

## 范围标记（强制）

```
full_series + canonical     完整系列 → 项目级最终定论
full_episode + provisional  只有单集 → 暂定，后续集数到位必须复核
test_sample + local_only    测试片段 → 只在测试命名空间生效
```

> 只有完整系列分析结果才能成为项目级 canonical 结论。

**环节 1 结束后停下，让用户确认。**

# 环节 2｜节奏驱动的段落划分

**不按自然段、页数或对白数量机械切割。**

## 边界信号（据此确定段落起止）

新目标出现 / 新威胁出现 / 重要信息揭示 / 关键道具出现 / 角色状态改变 / 人物关系改变 / 阵营立场改变 / 环境状态改变 / 剧情完成一次反转 / 出现适合作结尾钩子的状态

## 单段结构（九字段，一个都不能省）

```
段落编号：      时间范围：      段落名称：
剧情任务：      进入状态：      核心过程：
核心转折：      退出状态：      下一段连接锚点：
```

另附：`对白`（标说话人与落点秒数；配角/群演台词可标为环境音）、`forbidden_future`（本段绝不能提前出现的后续剧情元素）。

## 划分要求

- 每段约 15 秒，完成一个明确剧情任务
- 段落开始能承接上一段，结尾能推动下一段
- **不能把同一关键动作的原因和结果无意义拆开**
- **不能让段落结尾停在没有信息价值的位置**

判断量参考：15 秒通常容纳 2-3 句对白、1 个情绪节拍。对白超 3 句要么拆段，要么把配角台词降级为环境议论声。

`forbidden_future` 从全剧时间轴反推——凡是后续段落才揭晓的视觉元素，在本段显式列为禁止项，最终写进两种提示词。这是环节 11「提前生成后续剧情」检查项的数据来源。

# 环节 3｜状态时间线管理

状态时间线是整个系统的**连续性核心**。本体系没有首帧链，段间衔接完全靠它。

## 核心关系

> **上一段退出状态 = 下一段进入状态**
> 指客观状态一致，不要求前后画面构图完全相同。

生成每段进入状态时，**先复制上一段的退出状态再增量修改**，不要重新描述——重写就会漂移。

## 状态分类

| 类 | 取值 |
| --- | --- |
| 人物 | 健康/受伤/昏迷/苏醒/被控制/被释放/换装/衰老/觉醒/情绪改变/身份暴露/持有道具/失去道具 |
| 道具 | 完整/开启/关闭/装满/空置/破碎/丢失/转移持有人/被没收/被消耗 |
| 场景 | 白天/夜晚/雨天/雷暴/火灾/破坏前/破坏后/人群聚集/战斗后 |
| 生物与特殊元素 | 完整/受伤/死亡/进化/能量增强/能量衰弱/形态切换 |

## 状态记录格式

```
状态编号：      状态对象：      涉及的基础资产：
首次出现段落：  持续范围：      触发事件：
进入状态：      退出状态：      是否不可逆：
后续依赖段落：  是否需要生产连续性锚点：
```

## 不可逆原则

已破碎的道具不能自动恢复；已被没收的物品不能重新出现；已产生的伤口不能无原因消失；已完成的换装不能无原因返回旧服装；已死亡的角色不能再以正常状态出现；已受损的固定生物不能自动恢复完整；持有人变化后必须由新持有人继续持有。

## 强制校验

跑完全部段落后，**机械比对每对相邻段的 exit/entry**，不一致的当场列出并修正，不带病进入环节 4。

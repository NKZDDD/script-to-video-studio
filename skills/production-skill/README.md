## 当前规则
- 先确定核心冲突、观众情绪、信息揭示、视觉证据及段尾观看动机，再安排镜头任务、视觉中心、进入退出和人物表演；分析留内部。
- 可自主优化表现方式并补充合乎情境的行为，保持核心剧情事实与因果，不因原稿未写小动作就逐项请求确认。
- 用户要求与具体剧情决定镜头和表演，不固定切镜数、每镜时长、慢镜、招式、开场和收尾。
- SEG按项目锁定总长；P1先检查有效剧情能自然覆盖时长且不过载，再定段界和ABC，不靠拖镜头填空。30秒项目不套15秒门禁。实际模型接口能力单独核实，不静默拆段或改参数。
- 材料编译可以交planned任务；实际生成必须父图就绪，提交还须核对图片确实随请求上传。
- 固定LOC保留完整无人环境，SCSTATE加入当前人员、临时布置和现场活动；复用时区分连续、换时与持续变化，不每SEG重画，详见asset-first-pipeline。
- 无人LOC与含人物空间状态分开。共同母图为来源，每个交接边界一次生成完整ABC，核对三区后参考同版整板生成独立A/B/C并对原区核验。视频使用入板B/C、出板A，不上传整板；禁止先分区创作后合成，不采用裁切代替参考生图。无关联天然转场免ABC。
- 同场同状态同镜头范围只有一个空间来源；一个SEG多个场景保留各自必要图，不限制整段只有一张场景图。
- 人物精细度与血缘关系分开；非血亲不自动遗传骨相。顶视图与面部细节按实际镜头需要启用，人物表演依据剧情与关系设计，已移除六阶段情绪和固定动作配方。
- 视频统一七段式：画幅风格、参考图、站位声明、时间轴分镜、接续状态、音效、强制禁止项。Image N绑定实际图片，无SBSHEET、无时间码、无固定500字门禁。
- 原生音频不自动增加后期配音，无字幕不把对白写成字幕。
- 镜头内画面、发声角色、对白/内心独白原文、口型反应及环境动作声分行；每次发声明确归属，只有原文字段可生成语言人声，角色名和提示说明不朗读。多人同镜可轮流说话，无人声省略原文字段；实际效果需试听核对。
- 按用户指定的内容和格式交付；图册、曲线、看板及报告按需提供，平台不自动追加。必要内部检查、资产任务与引用仍保持完整。

主模型路线为Seedance 2.5 / Seedance 2.0；即梦仅按用户明确要求适配。

## 检查与工具
- scripts/check_package.py：静态包检查，不证明全部语义和生产结果通过。
- scripts/audit_material_refs.py：材料/引用、可选文件及上传清单分层检查；不替代完整外部契约schema、服务商回执或视觉验收。
  默认允许合法前向引用；仅执行器明确要求按行执行时启用`--require-parent-first`检查行序适配。`scripts/test_audit_material_order.py`验证这一区分，行序通过不代表父图已就绪。
- scripts/audit_abc_flow.py：以内部复核台账检查ABC整板→区域派生→视频的依赖、三区同版来源、前尾A/后首B与空间C引用及缺失；用法见abc-handoff-board第7节，台账不加入生产JSONL或提示词。scripts/test_audit_abc_flow.py提供回归测试。
- scripts/build_board_lite.py：MD转离线HTML，保留原始块与精确段号。

- scripts/generate_emotion_curve.py：内部节拍可视化。
只有实际执行的层才能报告通过，无视频不声称原段直拼通过。

### 非语言人声的边界
呼吸、叹息、抽泣等按剧情需要写在现有“环境与动作声”中，说明声源人物及发生动作，只生成相应声音，不朗读名称；不是新增对白。现场对白对应口型，内心独白不做说话口型；呼吸或哭泣允许自然嘴部动作。语言人声只来自已明确绑定角色的对白/内心独白原文，不新增旁白、解说或未写台词。

引用脚本按所选契约运行：V3.0使用默认v3模式，其他格式只在内部归一后使用internal模式，适配和检查边界见asset-first-pipeline“检查输入与契约适配”；不要为通过脚本擅改用户交付格式。

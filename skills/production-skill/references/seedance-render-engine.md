# 视频生成与时长预算
唯一投喂模板见 `model-adapters.md` §五。不得复制旧五段式、时间码或以模型限制名义固定镜头套路。

## 1. 一次生成与内部镜头
- SEG是一次视频生成，按用户锁定总时长。镜头为其内部叙事单位，没有全局固定数量、最低时长或切镜频率。
- 固定SEG时长D、总生产时长T可先按T/D规划；非整除时明确末段与总长安排，不暗中补长、裁切或拆段。例如90秒、30秒SEG为3段，不套180秒必须14～15组。
- P1按dialogue-speed-check核算每段的有效剧情、对白、动作、停顿是否自然充足且不过载；T/D只确定段数，不能证明内容足够。先调整分割点，再设计ABC，不能为迁就板而拖长镜头。同一时刻发生的动作与对白不重复相加。内部可细分节拍，投喂只输出[镜头N]与事件顺序。
- 实际平台能力记录包括时长、组内多镜、参考容量、音频和模式组合。未知待核实；接口不支持锁定方案时报告，不擅自改成多个独立片段或后期拼镜。

## 2. 创作决策
依据cinematic-dramaturgy-rules把核心冲突、观众情绪、揭示顺序、视觉证据和观看动机落实到每镜任务、视觉中心及进出点。用户要求、剧情任务、空间可实现性与交接状态共同决定景别、机位、运镜、节奏、慢镜、打击反馈和结束方式。人物表演遵story-directed-performance，不从情绪配方取动作。动作资料库是可选表达，不是全局必选清单。
- 高密度动作可内部逐事件核算发力、接触、受力、落点；普通对白无需微步进。
- Hit-Stop、火花、震颤声按材质与表现需求选用，不强制三件套；徒手、术法、暗杀不硬塞金属火花或肘击。
- 特效是否有物理载体按世界观与剧情；辨识度可用外形、材质、动作路径或色彩，不强制双色粒子。
- 首镜服从入板B，末镜服从出板A；无ABC按剧情自然开闭，不统一定格、切黑或余烬收尾。
- 镜头不得为凑构图无因挪动人物、车辆或建筑。

## 3. 空间与输入
按 `abc-handoff-board.md` §1.1：共同母图与必要资产→一次生成完整ABC→三区及跨板空间核对→参考同版整板生成独立A/B/C→对原区核验→视频；禁止先分区后合成。入板C只负责所属场景的开场状态；当前场景/状态/镜头范围未被入板C覆盖且需要参考时使用本场母图；一次性独立场景可按asset-first-pipeline豁免，连续连接区域仍须明确。
**同一SEG可以有多个场景及多张场景参考**，逐图标明镜头范围。同场同状态同范围不并投竞争控制图。角色道具只补身份外观。无关联转场不用ABC、不强制后场伏笔。

现场丰富度继承asset-first-pipeline定义的当前SCSTATE。背景人员、设施、物件和活动区域先在母图中成立，视频只安排可达活动与状态演进；特写不要求全员入画，切回全景不无因丢人。新时刻或事件不照搬旧群众与布置，持续损坏和遗留物不得自动恢复；必要新增配置先补上游。

## 4. 声音
- 原生音频时在同一视频任务内安排说话人、对白、嘴部动作和音效。声音层不是独立后期任务。
- 用户选择后期配音才输出对应声音任务；不按模型名字臆断可用性。
- 镜头内按model-adapters第5节分行区分画面、发声角色、对白原文/内心独白原文、口型与反应、环境与动作声；只朗读绑定角色的原文，不朗读说明或标签。不再用大括号对白和尖括号音效混排；无人声时省略原文字段。多人同镜可逐个发声块轮流表达，不强制换人切镜；抢话按剧情明确安排。无字幕不将对白输出为屏幕文字。
- 声音随动作与剧情事件安排，不强制命中抽空、固定电平或每次动作都加巨响。对白可懂、音效不过度遮盖；具体混音数值属目标而非生成保证。

## 5. 输出与检查
完整七段式及示例仅维护在 `model-adapters.md` §五，各种画幅使用同一结构并调整构图。
检查层级：材料/引用→实际父图→实际上传→图像空间→成片与直拼。没有成片不能称直拼通过；只有任务不能称图片已生成。
按需读取对白、表演、动作模块，最终按 `★ prompt-feeding-checklist.md` 与 `quality-gate-review.md` 检查。

### 非语言人声的边界
呼吸、叹息、抽泣等按剧情需要写在现有“环境与动作声”中，说明声源人物及发生动作，只生成相应声音，不朗读名称；不是新增对白。现场对白对应口型，内心独白不做说话口型；呼吸或哭泣允许自然嘴部动作。语言人声只来自已明确绑定角色的对白/内心独白原文，不新增旁白、解说或未写台词。

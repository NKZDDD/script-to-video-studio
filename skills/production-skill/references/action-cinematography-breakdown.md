# 华语动作电影拉片级分镜与运镜工程规范 (Action Cinematography & Shot Breakdown)

本指南深度解构《一代宗师》《师父》《杀破狼》《导火线》《九龙城寨之围城》等顶级华语动作神作的分镜视听语法，转化为扩散模型可直接执行的分镜规范。

> 视频投喂分镜按镜头编号和动作顺序组织，不输出起止时间码或精确秒数；以下动作时长分析仅用于内部预算，输出时按 `model-adapters.md` §5转换。

---

## 一、 经典动作分镜五大核心法则

### 1. 景别阶梯跃迁呼吸法 (Shot-Scale Ladder)
* 景别可按叙事变化；一种可选方案是 `特写（发劲微观） -> 中景（双人攻防） -> 全景（空间动势与破坏）` 阶梯跃迁。
* 特写可直接切大远景，若反差有叙事动机且空间可读；不机械禁止跨级景别。

### 2. 视线落点连续性 (Eye-Trace Continuity)
* 镜头切接可用视线落点承接，也可通过人物视线、运动或声音引导注意力转移；不强制相同屏幕坐标，不为迁就落点搬动人物或地标。

### 3. 动势衔接 (Match on Action)
* 选择动作连续匹配时，按前镜实际相位继续，保持可解释的速度、方向与受力；是否击中由剧情决定。合法省略或转向反应镜头时，保留必要因果，不强制展示整个挥拳过程。

### 4. 同向加速运镜 (Camera Sync Velocity)
* 需要强化动势时，镜头可与攻击动作方向一致（如右勾拳向左轰出，镜头以同速度向左平移跟拍），速度感来源是“镜头与动作的同向合力”，而不是画面本身的乱晃。

### 5. 近景生理破坏与全景动势交代
* **中远景看动势与空间**：走位路线、身体腾空舒展、障碍破坏；
* **近景与特写看生理破坏**：骨骼受力凹陷、汗水血沫喷溅、肌肉撕扯、眼神杀意。

## 二、 老李“三手法六式”镜头衔接体系

* **三手法**：
  1. 换机位（改变拍摄角度与视角，保持主体动作连续）；
  2. 切景别（特写切中景，中景切全景，由微观入宏观）；
  3. 跨段反应（攻击击出瞬间切受击方防御或受创表情）。
* **六式**：
  * ① 动作连续切（挥招前半段切命中后半段）；
  * ② 反应镜头切（攻方重击切守方瞳孔骤缩/咳血）；
  * ③ 景别跳切（长距离突进由全景跳入近景刺杀）；
  * ④ 视线引导切（主角转头看向右侧，顺视线切右侧出现的威胁）；
  * ⑤ 遮挡过渡切（前景立柱/人影掠过遮挡瞬间完成场景切换）；
  * ⑥ 动势匹配切（上一镜向右翻滚，下一镜向右滑步冲拳）。

## 三、 机位-动作语义绑定表（打斗镜头机位选择逻辑）

> 先理解动作意图，再选择能表达受力与体量的机位。已有ABC或明确机位时，联合核对动作能否在该空间完成；不是无条件重定摄影机。

| 动作语义 | 机位选择 | 为什么对 |
|---|---|---|
| 贴地横扫 | 低机位贴地跟拍 | 看到剑芒水平切过群魔，高度差制造切割感 |
| 巨兽砸地 | 大仰角中景 | 体量压迫感拉满 |
| 风暴回旋 | FPV 第一人称旋转 | 代入旋转眩晕，主观感最强 |
| 千斤坠升空 | 俯拍起跳 → 仰拍升空 | 先压后升，力学过程可见 |
| 流星砸地 | 垂直俯视 Top-Down | 同心圆冲击波全景最清晰 |
| 360 辐射 | 极广角俯视 | 放射线全貌，力量向八方扩散可见 |
| 挑衅/神态 | 特写浅景深 | 表情记忆点，武戏中段人设锚 |
| 剑阵全爆 | 中景快速拉远 | 爆炸结果整体呈现 |
| 中场留白 | 按视线和叙事选机位 | 可用静默观察、运动中换档或环境动态，检查是否承担戏剧任务 |
| 巨浪扑杀 | 仰视广角跟摇 | 水墙压迫感，跟摇保持动态 |
| 逆斩天柱 | 极近仰拍 | 由下至上完整见斩线 |
| 断海收尾 | 超远景中心构图 | 奇观全貌，终帧仪式感 |

* **使用方式**：按动作语义查表作为候选，不将某动作固定为唯一机位；只要动作、落点与空间可读，其他角度也可以成立。

## 四、 拆解稿判型与重写（长运镜 ONER vs 多镜剪辑）

> ⚠️ 2026-09-02 实测翻车：把 Gemini 拆解稿（动作分解）当成剪辑点重组，逐镜写“换机位”，结果模型渲染成过山车运镜、画面发飘。**拆解稿≠剪辑点**，拿到必须先判型。

### 1. 判型方法
* **长运镜（ONER）**：原片一个镜头从头跟到尾，动作连续发生，拆解稿只是“动作分解”；特征是运镜轨迹连续（贴地→抬升→环绕→拉远），无硬切。
* **多镜剪辑**：原片多个镜头拼接，拆解稿每个“镜头”是真实剪辑点；特征是有遮挡/白闪/硬切转场。
* **判据**：结合原片或明确镜头记录判断；没有转场字样不等于长镜。依据不足时标明待核实，不自行把动作条目变成切镜。

### 2. 长运镜重写规则（散→聚）
* **连续长镜**：最终以单一 `[镜头1]` 写完整运镜与事件序列；内部动作分拍不代表切镜，不凭动作数新增镜号；
* **机位不切换，只“跟随动作自然运动”**：用“镜头随她踏地借力冲天而起的动作自然抬升、螺旋环绕上升”替代“俯拍起跳→仰拍升空”的分镜写法；
* **动作在轨迹上展开**：横扫→砸地→升空→剑阵，全部发生在同一镜头内，用“同一运镜内/同一镜头内”串接；
* **SFX 层层递进**：一个 `[SFX: ...]` 序列按动作顺序排列（重刃破空→山岳崩裂→风暴呼啸→破障→万剑蜂鸣）；
* **观看重点**：明确观众此刻关注什么，可以是单人、双人关系或群体运动；不声称模型每段只能处理一个主角色。
* **开场景别**：优先承接 ABC B；无入板时按叙事选择近景、全景或其他景别。主体占比、背景视差、前景掠过都是工具，不统一强制主角中近景。

### 3. 多镜剪辑重写规则
* 按真实镜头切点编号；一次生成的 SEG 时长限制不适用于内部每镜。镜头长短和数量由剧情、动作及验证结果决定，无每镜4秒下限。

### 4. 连续长镜自查清单（仅在选择ONER时）
- [ ] 整条时间轴是否只有一个运镜轨迹（无“换机位/切到/转场”字样）？
- [ ] 机位变化是否写成“镜头随动作自然运动”（抬升/环绕/拉远/跟摇）？
- [ ] 是否每条拆解动作都归入了这条轨迹，没有独立成镜？
- [ ] SFX 是否按动作顺序递进，而非每段各一个？

### 5. 内部长运镜设计素材（不得直接投喂）

> 下方范例为「女帝战巨兽」拆解稿的聚合重写版，单一连续运镜（低空掠过→随升空自然抬升→螺旋环绕→随剑雨俯冲），**结尾直接万剑齐发轰地，无蓄势定格**。用于理解连续轨迹，不固定剧情节拍。导出前转换为 `model-adapters.md` 七段式：画幅风格、参考图、站位声明、时间轴分镜、接续状态、音效、强制禁止项；单镜仍用 `[镜头1]`，删除所有精确时点。

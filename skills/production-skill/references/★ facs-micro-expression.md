# 面部细节与镜头可读性

人物表演主依据是story-directed-performance.md。本文件仅在所选表演确需面部细节、或生成结果发生脸部失真时辅助表达；历史文件名保留用于路由，不再提供FACS情绪配方、固定强度档、四区填写流程或真假笑判定模板。

## 何时细化

先明确这场戏中角色在做什么、观众需看懂什么。只有当前镜头中的某个面部变化承担实际区别，才进一步说清其发生部位、可见变化及与台词和动作的关系。普通对白、近景、重要角色均不自动触发精细拆解。

只描述看得见且有作用的部分。侧脸、遮眼、背影、远景不能硬加不可见面部要求；根据叙事任务调整取景或表达。身份稳定不等于表情冻结，不需要为每种情绪制作固定表情库。

## 描述与约束

- 使用自然画面语言，具体到足以区分当前演法即可。需要分清唇部变化或动作方向时可查facs-au-dictionary中的形态说明，不查“情绪对应答案”。
- 表情可以先于、伴随或晚于对白变化，可以保持跨镜状态，也可以几乎不变。时序随剧情，不固定眨眼频率、惊讶时限、动作幅度或句尾回落。
- 不通过笑时眼睛是否参与、视线偏移、吞咽等单项动作判定真诚、撒谎或心理；若本场需要这些动作，其含义由人物行为和上下文建立。
- 单侧动作确实影响连续性时写清人物自身哪一侧；区分人物左右与画面左右。不要求所有表情不对称或配挑眉。
- 同一部位不要在同一时刻被要求做相反动作；若先后改变，写清事件关系。说话、呼吸、手部行动与表情协同，不为了复杂度叠加所有细节。
- 检查非预期脸型漂移、遮挡错误和口型冲突。强烈表情不自动判错；动作少也不自动判高级。

AU编号、内部强度码、配方号及分析记录不进入投喂正文。不要求另交cue表或角色情绪库；材料与实图、声音及成片验收仍分层进行。规则表达清楚不证明模型已准确执行。

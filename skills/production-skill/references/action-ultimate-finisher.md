# 视觉巅峰大招与终结技体系 (Ultimate Finishers & VFX Burst System)

本规则库为“大招释放、视觉奇观与终结技”的可选设计工具，用户、剧情、角色能力、模型适配与ABC优先；内部时长仅作预算，不进入投喂正文。适用于 3D国漫、二次元漫剧、写实影视、仙侠修真、现代格斗与科幻动作全题材。

---

## 一、 视觉巅峰五要素（按需组合）

大幅动作、快节奏、宽景、特效变化和多段运镜都只是可选手法。按此刻的剧情结果、观众注意力与人物能力选择；静止、特写、慢节奏或无特效同样可以承担高潮。没有采用某手法不是缺陷，不为补齐组合增加动作、破坏或镜头。

---

## 二、 终结技三幕结构（破局 $\rightarrow$ 绽放 $\rightarrow$ 余震）

可用破局、爆发、余震组织终结技，也可直接一击或省略中间过程；以剧情与交接状态为准：

```
┌─────────────────────────┐       ┌─────────────────────────┐       ┌─────────────────────────┐
│   第一幕 · 破局 (Break)  │ ───>  │   第二幕 · 绽放 (Burst)  │ ───>  │   第三幕 · 余震 (Shock)  │
│ 打破攻防平衡, 制造绝对破绽│       │ 大招全力输出, 视觉巅峰  │       │ 冲击扩散, 骨肉形变与地裂 │
└─────────────────────────┘       └─────────────────────────┘       └─────────────────────────┘
```

### 1. 第一幕 · 破局（打破当前攻防平衡，0.5~1.0s）
* **化劲/借力破防**：掌心一搭引开对方格挡，防线瞬间向两侧崩开；
* **重击破格**：全力一击砸在双臂上，硬生生弹开防御架子；
* **下盘破坏**：贴地扫腿/踩脚截腿，直接摧毁对方支撑根基；
* **入身/走圈绕背**：踏入攻击线内侧绕至死角，正面防守全部失效；
* **时空截击**：在对方出招启动瞬间以更快速度截断其前臂，迫使其防御崩溃。

### 2. 第二幕 · 绽放（大招全力输出，1.5~2.5s）
* **凌空下劈 / 踏空暴扣**：腾空至最高点，腿/武器如重斧自上而下全力劈落，重力加持；
* **贯穿式寸劲直击**：半步崩拳/穿心订桥/寸劲标指，劲力聚于一点直贯心口，空气被击穿形成音爆气穴；
* **多段旋风连斩/连踢**：540°水平旋风腿/千霜环身斩/旋身连环铲，离心力叠加形成风暴；
* **神兵/神能绝杀**：
  * 剑法：红紫/冷白巨型满月剑光波正面贯穿，万剑归宗自虚空下坠；
  * 太刀居合：时停霜幕破裂，居合一闪拔刀，空间撕裂出细微电痕；
  * 火焰重斩：火红刀焰收束为极亮火核后爆燃成巨型弯月火海；
  * 摔投贯地：过肩摔/裏投/双膝跪压，将对手整个身躯沿巨大弧线轰入地面。

### 3. 第三幕 · 余震（终结技后的物理与环境反馈，1.0~1.5s）
* **地面碎裂与塌陷**：命中点地面呈蛛网状放射性龟裂，碎石受气浪掀起滞空；
* **环形冲击波扩散**：以命中接触点为圆心，高压气浪呈环形向外狂暴震荡，掀起尘帘；
* **受击者形变与嵌入**：受击者身躯剧烈弓成虾形，倒飞数米深嵌水泥墙体或砸裂地面；
* **气血/暗劲透体**：后背衣物“砰”地炸出放射状微孔，血雾自嘴角/创口呈锥形喷散；
* **交接优先**：作为有关联后段的出点时，最末帧须符合出板A的动作相位，不追加冻结停留或黑场；后段从该板B切入，C维持后段空间。无关联天然转场免ABC。终篇按叙事选择爆点、余波、悬念或切黑。
* **收尾选择**：可停在命中、余波或收势，但不要为套预设追加冻结尾巴；仅在该边界启用ABC出板时服从出板A。无关联天然转场免板，不因存在下一段而强制加板。

## 四、 特效生长三段论（时间维度）

需要展示能量积累时，可采用以下生长过程；突发爆发或省略前奏也可按剧情使用：

1. **萌芽期（0.3~0.5s，攻击启动）**：出招点（指尖/拳面/刀格）泛起微弱但清晰的高亮星芒或气旋，预告大招来临，拉满观众期待；
2. **生长期（0.5~1.0s，位移与蓄力推进）**：能量沿出招轨迹快速膨胀壮大，密度与亮度呈梯度倍增，向攻击部位核心收束压缩；
3. **绽放期（0.2~0.5s，命中瞬间）**：能量在接触点彻底引爆，炸开巨型环形冲击波、满月光刃或地裂气浪，释放全部张力；
4. **余韵层（0.3~0.5s，环境留痕）**：地面焦痕冒烟、冰晶碎屑飘散、空气热扭曲波纹久久不散。

## 五、 终结技前的节奏反差

高速对攻后可接短促观察、运动中蓄力、环境反应或持续追击。慢镜、命中微停顿与静默只在叙事需要且模型适配允许时选用，不强制0.3秒冻结，不预设终结技必有蓄力。时长留在内部预算，投喂用事件关系描述。

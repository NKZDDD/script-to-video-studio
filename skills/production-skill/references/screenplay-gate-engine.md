# 工业级五阶门控剧本引擎与去 AI 机械感视听法则 (Screenplay Gate Engine)

本模块规范了全题材（涵盖古装武侠、现代都市、悬疑脑洞、动作枪战、科幻等）短剧/漫剧从概念到专业剧本页的工业化生产标准。核心原则：**剧本即唯一真理源 (Screenplay as Source of Truth)**，所有角色、场景、道具资产自动从剧本文本双向绑定并派生。

---

## 一、 工业五阶门控开发流水线 (5-Stage Gate Pipeline)

按任务范围使用以下检查层次。已有原稿时保留核心事件与权限边界，不为套结构强改剧情；只做片段生产时不强求重写全剧。具体呈现可自主优化，包含镜头、信息揭示、声音和合乎人物情境的小行为，详见story-directed-performance。

### Gate 1: Premise（核心前提与黄金 3 秒钩子）
* **30 字前提公式**：`[主角] + [核心欲望] + [不可抗力阻碍] + [失败的致命代价]`。
* **开场钩子选项**（按剧情选择，不限于以下类型）：
  1. 极端悬念钩（直接把枪口/刀尖对准主角咽喉，生死悬于一瞬）；
  2. 认知反差钩（看似最弱的外卖员/赘婿/乞丐，展现出颠覆常理的宗师特权）；
  3. 情绪爆发钩（至亲惨遭凌辱/婚约撕毁/绝境背叛，怒气值瞬间拉满）；
  4. 视觉奇观钩（天雷裂空/上古法相降临/超维异象爆发）。

### Gate 2: Structure（宏观三幕比例与分集卡点）
* **结构比例参考**：建立、冲突与转折的比例服从故事和实际目标时长，30%/50%/20%仅是可选分析框架，不固定每集100秒。
* **分段先验内容**：按dialogue-speed-check核算每个SEG有效剧情、对白、动作和有意义留白能否自然覆盖锁定时长且不过载。同期事件不重复计时，不按提示词长短判断内容是否充足；不足先在授权范围内重排相邻节拍与分割点，不靠拖镜头、重复反应或增写无用台词凑时长。先定内容和段界，后设计ABC；P3细化后复核并同步受影响交接。
* **结尾选择**：可停在决策、揭示、结果、余波或悬念。剧集未结束的SEG服从交接，不强制每段卡在攻击前一帧；生产前90秒也不自动改写成完整终局。

### Gate 3: Beat Sheet（场景因果节拍表）
* 每段从真实剧情明确核心冲突或任务、观众情绪的起点与变化、信息揭示顺序、关键视觉证据和继续观看的理由；这些是内部判断，不是固定五拍。观众感受不等同于人物表情，不靠加反转填表。
* 将判断传递给P3的镜头任务、视觉中心、进入退出和表演选择，按cinematic-dramaturgy-rules落实；不能只做节拍分析、出稿时又逐句配画面。
* **场次存在性法则**：检查场次是否承担剧情、人物、关系、空间或节奏作用；无作用的重复再考虑精简，不能自动删除原稿。
* **因果检查参考**：`场景目标 -> 遭遇阻碍 -> 升级行动 -> 意外转折 -> 产生不可逆新局面`。

### Gate 4: Worldview & Entity Bounds（世界观与实体边界约束）
* **时代法则**：明确时代背景（古代/民国/现代/赛博未来），锁定法律、战力天花板与技术极限。
* **人际关系网络（Relationship Graph）**：明确上下级、仇恨、盟友关系，杜绝无动机叛变。

### Gate 5: Professional Script Page（语义化工业标准排版）
```text
[场景序号] [内景/外景] · [具体地点] - [日景/夜景]
出场人物：@角色A、@角色B
环境氛围：[空间构图、天气、主导光源与声音质感]

[动作描述]（遵循反形容词法则，只写摄像机能拍到的物理动作与空间位移）

@角色A（依据当场目标、关系和前一事件设计的可见行为）
“（依据当场人物意图写出的实际台词，可直白也可含蓄）”

@角色B（由听到的信息及自身处境引发的反应）
“（台词内容）”
```

## 二、 去 AI 机械感三大法则 (Natural Screenplay Laws)

1. **角色压力与筹码追踪（Character Pressure Tracking）**：
   * 从实际人物关系判断对白的任务：传递信息、表达感情、协商、隐瞒或交锋，不把所有对话改成博弈；
   * 检查对话是否提供信息、关系、人物或压力变化；不强制每句都施压反击，允许必要的亲密、日常和过场。
2. **承重场景识别（Load-Bearing Scenes）**：
   * 识别承重戏与过场戏，按信息、情绪和因果安排表现篇幅。重要戏可以克制，过场也可需要多个镜头，不用微表情密度或固定镜头数衡量质量。
3. **冰山对白（Iceberg Dialogue & Anti-Exposition）**：
   * 按当前剧情作用判断解释与重复，双方知情不构成删除理由；提醒、控诉、试探、誓言、关系确认和情感表达可以直接说出已知事实。
   * 仅在已有改写权限内精简无叙事、人物、关系、情绪或必要理解作用的机械说明。潜台词、眼神和道具动作是可选表达，替代时须保留原句意图与必要信息，不强迫所有对白含蓄化；详见dialogue-doctor-7d“台词取舍依据”。

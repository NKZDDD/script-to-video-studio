# 角色资产板与亲缘/多梯队遗传推导规范 (Character Lineage & Asset Sheets)

> 🔗 P2角色资产规范。材料编译交planned出图任务，执行生成才交真实4 View图片；遵循asset-first-pipeline的模式与状态要求。

---

## 一、 标准角色 4 View 资产卡构成（CURRENT · V6.8）

每位 A/B 级核心角色的资产图必须包含以下要素：

1. **Face Close-up（面部特写）**：五官骨相、眉眼间距、瞳孔色泽、皮肤肌理。
2. **Views（4 View）**：Face Close-up（头部近景/面部特写）+ 无头 Front View（正面全身）、无头 Side View 90°（侧面全身）、无头 Rear View（背面全身），左右分区式布局。🗄️ LEGACY：旧「3/4 斜侧三视图」仅作历史兼容。
3. **Full Body（全身比例）**：身高比例尺（如 180cm / 168cm）、头身比（6.5~8 头身）。
4. **Detail Assets（细节材质）**：
   - Fabric Texture（服装布料微距肌理，如哑光羊毛、做旧皮质）
   - Hair Style（发型流向与碎发高光）
   - Button / Cuff Design（纽扣、袖口与配饰特写）
5. **HEX Color Palette（标准色值）**：
   - Primary（主色调，如 `#1A1E24` 炭黑）
   - Secondary（副色调，如 `#8C7355` 暖卡其）
   - Accent（点缀色，如 `#C23B22` 暗朱红）

## 二、 亲缘与多梯队角色推导引擎

角色重要程度与血缘关系是独立维度。统一画风、渲染与材质；每人外貌按身份和剧情设计，不把非血亲强行生成同一家族脸。

### 1. 梯队划分
- **第一梯队（T1 - 核心基准）**：男一号、女一号。率先锁定脸模与核心画风。
- **第二梯队（T2 - 重要配角）**：父母、子女、兄弟姐妹、情侣、核心反派。
- **第三梯队（T3 - 功能配角）**：同门、手下、管家、路人。

### 2. 亲缘遗传推导算法（推导后直接出图）

仅对剧本明确的血亲按需要体现相貌关联；养子女、姻亲、情侣、师徒、反派不因T2/T3身份继承骨相：
- **骨相继承**：根据具体血缘与人物设计选择可辨识的下颌、眼眶等关联，不固定遗传比例；
- **五官关联**：如母亲与女儿共享相同鼻型与眉形弧度，仅在眼尾纹理与面部胶原蛋白丰满度上作年龄化差异；
- **色彩呼应**：服装色彩按身份、家族文化和剧情设计，非遗传硬约束；
- **出图方式**：按上述继承参数，直接生成 T2 的 4 View 资产板（复用 T1 的底色/材质描述 + 差异化参数），并入 P2 第一批角色出图，锁定后进《资产图册》。

## 三、 输出指令规范

当用户输入 `/角色资产板`、`/角色遗传推导` 或 `/数字资产包` 时，系统按 `asset-first-pipeline.md` P2c·第一批执行：
1. 按请求范围确定实际需要的角色与核心画风，优先复用已有合格身份资产；不强制补齐男女主。材料模式编译任务，只有执行生成模式才实际出图；
2. 单独记录每个T2/T3与T1是否血亲；血亲按需关联外貌，非血亲独立设计。按任务模式交planned任务或实图；
3. 输出角色 16 项资产全量描述词（按用户Prompt语言与图片模型适配，不强制双语）；
4. 按用户所选格式交付必要的4 View资产任务或已生成图。亲缘关系和色值默认记入内部依据；仅在所选交付要求中需要时输出，不自动追加表格。

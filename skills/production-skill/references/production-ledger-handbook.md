# 《剧组资产图册》与工业化台账总控规范 (Production Ledger Handbook)

> 材料编译模式允许planned资源记录，真实图片列写待生产；不得用虚假路径填满。执行生成后才绑定实图和验收记录。

> 🔗 **流程位置：P2 数字资产包（见 `asset-first-pipeline.md` ★权威）**。本规范定义的产出不再只是文字台账，而是**附资产参考图的《资产图册》**——实际生成完成的角色/场景/道具绑定可投喂实图；材料模式绑定planned任务，成为 P3 分镜与 P4 投喂的唯一权威事实来源（Single Source of Truth）。**“名字+装扮”只是索引标签，资产=资产参考图。**

---

## 一、 资产图册核心架构（Markdown 标准结构）

内部资产记录服务于一致性，不等于每次必须交付图册。仅当用户请求图册时输出相应文件；指定JSONL/纯提示词时按契约承载必要资产与引用，不另加图册。以下是未指定格式时可采用的Markdown图册结构；只填写本次范围适用的内容，不为凑板块增产资产、曲线或视频：

```text
《[剧名]_资产图册.md》
├── 1. 风格与摄影基准（机型、镜头组、色温光系、参考电影、画幅锁定）
├── 2. 风险与合规监测（平台敏感词过滤、防封禁合规转译）
├── 3. 角色资产台账（CHR- 编码、层级、必定演员、运行范围、**资产参考图**）
├── 4. 声音与音效资产表（AUD- 编码、OS/对白/环境音、分层电平）
├── 5. 关键道具与资产表（PRP- 编码、关键特征、防穿模规范、**资产参考图**）
├── 6. 空间场景清单（SCN- 编码、空间类型、光线/时段、机位基准、**资产参考图**）
└── 7. 分集单元执行表（U01~Uxx、生成方式、渲染规格、状态）
```

> ⚠️ 相比旧版核心升级：CHR / SCN / PRP记录资源状态与图像来源；实际生成完成后填写资产参考图（角色 4 View 资产板 / 场景空间图 / 道具图），文字描述降级为索引标签。

## 二、 资产标准化编码规范

### 1. 角色资产编码（CHR-）
- **格式**：`CHR-[角色名]-[正面/侧面/状态/服装]`
- **必填字段**：
  | 字段 | 说明 | 示例 |
  |---|---|---|
  | **永久ID** | 角色全局唯一标识 | `CHR-荆恪-正面` |
  | **身份/设定** | 年龄、职业、核心性格 | 30岁男主，外表冷静寡言，眼神冷峻 |
  | **梯队分级** | A（核心主角）/ B（常驻配角）/ C（群众） | `A - 核心主角` |
  | **必定演员** | 绑定脸模/LoRA ID 或指定生成模型 | `ImageGen: 1024x1536 high-cinematic` |
  | **运行范围** | 登场集数与场景覆盖 | `第 1~12 集，全剧核心` |
  | **资产参考图** | **4 View 资产板（16:9 白底）**，内部台账/分镜登记；视频投喂按实际上传顺序写 `Image N = 资源 key，这张图是用途` | `@CHR-荆恪-正面` → 资产图文件 |

### 2. 声音资产编码（AUD-）
- **格式**：`AUD-[角色名/音效]-[类型]`
- **类型定义**（相对电平仅混音参考，按剧情选择，不是生成保证）：
  - `AUD-[角色]-OS`：内心独白（干燥近讲，相对电平 0 dB）
  - `AUD-[角色]-对白`：现场台词（环境空间感微混响，相对电平 0 dB）
  - `AUD-[场景/动作]-SFX`：物理碰撞与招式音效（相对电平 -6 dB）
  - `AUD-[情感/氛围]-BGM`：背景配乐（相对电平 -14 ~ -18 dB）

### 3. 关键道具资产编码（PRP-）
- **格式**：`PRP-[道具名]`
- **必填字段**：
  - 道具名称与属性（如 `PRP-金属打火机`：复古磨砂黑银双拼，带刻痕）
  - 剧情关键作用（如“第四集揭露身份的关键物证”）
  - 防穿模/防变异描述（材质、反光度、手持抓握基准）
  - **资产参考图**：关键道具出图，分镜引用 `@PRP-打火机`

### 4. 场景空间清单（SCN-）
- **格式**：`SCN-[场景名]`
- **空间属性**：室内/室外、日景/夜景、主色调（如暖橙晨光、冷蓝夜雨）
- **空间快照**：设定 3D 空间左右边界与 180° 轴线基准
- **资产参考图**：核心场景出空间资产图（建筑/材质/固定陈设/固定光源；机位示意留内部，不画入LOC），分镜引用 `@SCN-山门`
- **出图标准**：遵循 `asset-first-pipeline.md`“场景资产启用与覆盖”；内部记录已知复用范围、空间衔接需求、是否建图及可见区域覆盖，不以镜头数或戏种单独强制。

### 5. 分集单元执行表（U01~Uxx）
- **格式**：`U01` ~ `Uxx`，数量按总生产时长及项目SEG时长规划；90秒/30秒为3组，不设固定14组
- **单元属性**：视觉生成方式（图生视频/文生视频）、美术设定、对白与语速自检状态、渲染规格（9:16 / 16:9 4K）、状态（待生成/已初审/已定剪）。

## 三、 指令交互与输出格式示例

当用户输入 `/剧组产出册`、`/生成台账`、`/数字资产包` 或 `/资产图册` 时，系统按 `asset-first-pipeline.md` P2 流程执行：
1. 输出资产清单（编码＋10项五官＋6项服装材质＋独立血缘关系表），按已有授权核验完整性，不重复确认；
2. 材料模式交planned图片任务；执行模式按依赖分批生成并核验，用户明确要求逐批确认时才停等；
3. 图册登记实际生产状态，材料阶段实图栏标待生产，生成后才附真实图与路径；
4. 仅当用户需要建议且交付格式允许时提供P3推进建议；指定JSONL或纯提示词时不附诊断、建议或额外文件。`/数字资产包`也不自动等于请求Markdown图册。

## ABC交接台账（P3派生）
按 `abc-handoff-board.md` 逐边登记from_seg/to_seg、use_abc及原因。有承接需求的边界再登记board_key、版本、实际图片路径、A来源、B切镜方案、C空间、声音、依赖资产与验收状态；无关联只记天然转场，不登记虚构图片。ABC来自文字时间轴与P2基础资产，不能在分镜前凭空生成。视频引用顺序为入板B独立图→入板C独立图→出板A独立图→必要场景→人物→道具；区域图的确切母板版本跨段共享，Image号段内独立。

## 现场状态与复用记录
按asset-first-pipeline记录地点基准、当前SCSTATE、现场个体与群体区域、临时设施、背景活动、持续变化以及适用镜头。复用先判断状态是否匹配，必要才派生新状态；不新增重复资产类型，不给所有群众独立出图。此记录留内部或映射已选契约，不能成为额外交付表单。

## 唯一空间来源记录
按 `abc-handoff-board.md` §1.1登记场景、剧情状态、母图key/版本/实际路径、一次整板生成记录、区域派生任务及region/确切父板版本/实图路径/对原区核验、共同参考清单、A/B机位与C空间关系及跨区/跨板核对结果；记录每段镜头范围的空间来源和补图权限。一个时刻不能登记两套竞争站位，入板C与出板A分别约束起态与终态，中间必须有可达动作过程。更换A/B/C后同步两端镜头文字与清单，原视频使用版本保留。上述为内部生产记录，不自动新增外部JSONL字段。

# 镜头规格、景别变化与空间检查 (Camera Specs)

本文件是摄影设计工具，不是固定切镜配方。镜头选择服从用户、剧情、画幅、模型适配与 ABC；时长只在内部预算，投喂正文按镜头编号组织。

## 一、先区分镜头与生成段

- SEG 是一次视频生成单元；镜头是该段内部的摄影镜头。
- 模型/API 的生成时长限制只作用于 SEG，不能据此推导每个镜头至少若干秒。
- 镜头数量、运镜持续时间和景别变化没有全局固定下限或上限；以内容容量和生成验证为准。长镜与快速切镜均可用。
- 不用自编公式声称可预测平台完播率。

## 二、五要素设计检查

内部逐镜想清楚：景别、相对视角、俯仰角度、运镜方式、关注目标。固定机位、跟拍、推拉、升降、环绕或甩镜按需求选择。

投喂采用 `[镜头N]`分行块，景别、视角与运镜写入“画面”；“发声角色”和“对白原文/内心独白原文”与画面、口型反应、环境动作声分开，详见model-adapters第5节。不输出时间码、逐镜秒数或独立“跟随@谁”栏。跟随关系在运镜和动作中自然表达；多人轮流说话不强制切镜。

## 三、空间与动作可读性

- 中景/全景可用斜角建立纵深，也可用侧面展示轮廓与轨迹；不存在全局90°禁令。
- 大幅动作通常需要交代身体与落点，小动作可用近景；遮挡或局部取景若承担叙事任务也可采用。
- 允许连续拉远或移动摄影机，逐步展示原本就在空间中的人物；核对可行路线、遮挡与显露顺序，不用固定景别人数限制代替判断，未入画的反应不要求可见。
- 新显露的必要区域与动作路线须在同源上游参考中提前提供，不能让视频自行补布局；材料补任务，执行补实图，缺失未解决不提交。详见asset-first-pipeline“必要空间前置”。
- 从空间母图或 ABC C 的实际位置推导机位；变化的是摄影机，不能暗中移动人、马车或门。
- 视线、屏幕运动方向、背景遮挡与轴线必须可解释。跨场时按空间域分别继承，不让前场 C 管新场景。

## 四、可选镜头组织

- **阶梯推进**：细节 → 双人关系 → 环境后果，适合逐步展开。
- **尺度反差**：微距 → 大远景，适合对比；切点仍需视线、动作或叙事依据。
- **同景别反打**：角度或表演信息变化即可，不强制每镜换景别。
- **连续长镜**：一条可行运镜轨迹承载多个动作；不因动作分拍而人为拆镜。
- **节奏反差**：观察、密集动作、短暂停顿、慢镜或实时速度按剧情选择。慢镜不是全局必用或禁用；适配能力不确定时先验证，不能声称一定可执行。

## 五、受击反馈工具箱

可选短促受力震动、镜头偏转、焦点转移、方向性动态模糊与速度变化。只选择帮助观众理解受力的手法，不能每次命中都同时叠满。

## 六、开场与收尾

开场优先已有 ABC B 或独立场景入口；不强制双人硬撞、眼睛特写或主角中近景。结尾优先出板 A；无后续关联时可按剧情选命中、悬念、余波或切黑。不要为了风格预设补冻帧、黑场或重复动作。

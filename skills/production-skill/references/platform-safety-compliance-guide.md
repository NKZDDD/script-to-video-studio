# 平台适配中的表现程度与剧情结果

画面呈现与事件结果分开判断。按用户视觉要求和实际平台规则调整表现程度，不能把“死亡”自动改成“威胁”或“制伏”，也不能把伤害、幸存、证据或胜负改成另一件事。

- 需要减弱直观创伤时，可按剧情选择画外事件、遮挡、声响、反应或事后状态，仍让观众理解已经发生的结果；不要用无关环境破坏冒充关键人物结局。
- 普通受力按实际动作与风格描述，不为替换词语增加夸张伤害。不维护未经验证的通用禁词表，不承诺换词就能通过。
- 材料编译遵守已知约束；实际提交遇到平台限制时核实当前规则与返回结果。允许的表达仍无法保留关键结果时，说明具体冲突并协商改编范围，不静默改剧情或规避审核。
- 本文不提供新的剧情授权；创作权限、人物能力和已确认事件以用户要求及项目剧情为准。

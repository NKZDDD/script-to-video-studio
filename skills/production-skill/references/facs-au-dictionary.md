# 面部动作形态辨析（无情绪配方）

历史文件名保留用于引用兼容。本文件只帮助把已经依据剧情选定的可见动作说清，不提供AU编码、肌肉学权威断言、情绪标签对应或组合演法；不要从下表选择一串动作填满表演。

| 容易混淆的描述 | 形态区别 |
|---|---|
| 内眉与外眉 | 靠近鼻梁的眉头与靠近太阳穴的眉尾是不同部位 |
| 抬眉与聚眉 | 眉毛向上移动与眉间距离收窄不等同 |
| 睁眼与收紧眼睑 | 眼睛开口增大与眼睑边缘收紧不是同一个要求；按实际画面说明 |
| 上唇与嘴角 | 上唇向上移动不等于两侧嘴角上提 |
| 嘴角方向 | 向上、向下与向侧后移动须分别表述，单侧变化说明角色自身左右 |
| 抿唇与开口 | 双唇压在一起与分开是不同状态；对白期间按发音变化，不要求全程抿死仍有口型 |
| 下颌与头部 | 下巴随张口运动，不等同于整个头低下或抬起 |
| 视线与头向 | 眼睛注视的对象与头部朝向可以不同，明确可见目标和空间位置 |

这些形态本身不指定心理含义。呼吸、吞咽、眨眼、视线、肩背及手部也没有固定情绪答案或常规频率要求。只为当前角色与镜头的实际需要描述；具体应用见story-directed-performance.md与★ facs-micro-expression.md。

## 一、 法宝/法器媒介体系（施法不靠拳头）

法术的来源按世界观决定：可以经法宝、身体、结印或环境发动。使用法宝时交代本体与施法动作；没有法宝的角色不能为套本表新增道具。以下为法宝分支资料：

| 法宝类型 | 施法动作范式 | 特效出口 |
|---|---|---|
| **乐器系**（笛/琴/箫/铃） | 横挡身前 / 举笛朝天 / 拨弦 | 音波光柱、音律波纹、礼乐符文、花涡 |
| **扇系**（骨扇/羽扇/灵扇） | 扇面展开 / 抛向空中放大 / 旋转蓄能 / 挥扇 | 扇形冲击波、万道金光、雷龙、剑气暴雨 |
| **印/令/玺系** | 结印虚按 / 抛印悬空 | 法阵铺展、空间镇压、道纹光轮 |
| **拂尘/笔/卷轴系** | 挥洒 / 凌空书符 | 符纹洪流、墨色剑光、禁制锁链 |

**按实际来源描述**：若使用法宝，可写其材质、施法动作与出口；其他术法写对应身体/环境来源。避免只有“施法”而没有可见过程，不要求所有法术有实体媒介。

## 二、 五行/元素属性术法词库（属性即视觉语言）

玄幻角色按资产绑定属性与配色，可单色或多色，不因范例强制双色，属性决定术法形态与粒子配色：

| 属性 | 术法形态 | 双色粒子 | 示例 |
|---|---|---|---|
| **木/花灵** | 荆棘花藤刺穿虚空、花叶飞刃、花罩、花瓣弹坑 | 粉白 + 草木青 | 玉笛花灵：花刃暴雨、音波花涡 |
| **雷** | 雷蛇狂舞、电弧跳跃、雷龙咆哮、电离焦痕 | 蓝白 + 紫电 | 骨扇女主：雷龙冲阵 |
| **金** | 万道金光、能量巨扇、光柱镇压 | 亮金 + 暖白 | 骨扇女主：巨扇天降、金光暴雨 |
| **水/冰** | 寒潮、冰棱、雾气、霜痕 | 冰蓝 + 银白 | 霜系仙尊 |
| **火** | 火龙卷、灼核、熔岩地裂 | 赤红 + 暗金 | 熔岩尊者 |
| **音** | 音波波纹、古乐锐响、礼乐符文 | 粉金 + 白 | 玉笛花灵：万古风歌 |

**属性攻防链**：护体罡气（角色防御层）→ 术法攻击需"破罡"（如花刃划开护体罡气如薄纸）→ 防御术法（花罩/禁制）→ 爆裂转攻（花罩炸裂化万刃）。纯术法攻防用术法因果；若人物实际进行物理格挡，则只在该动作上使用物理检查，不强制每次经历整条链。

## 三、 术法攻防循环（玄幻版防守三态）

替代武侠防守三态（完整态→崩防线→过渡态），玄幻用**术法层攻防**：

1. **祭起防御术法**：花罩/护体光罩/禁制升起，挡下四面术法轰击（写清防御形态：花罩/罡气/光盾）；
2. **破防临界**：防御被撕裂/炸裂（如花罩被轰出裂纹、罡气如纸被划开）；
3. **爆裂转攻**：防御术法炸裂瞬间化作攻击（花罩爆裂→千万花刃切割四方、罡气碎→剑气四射）——防守转攻是可选高光，也可破防败退或持续防守；
4. **瞬移/残影**：闪现位移（原地留残影，真身现于十丈外），规避与进攻一体。

## 四、 能量具象化四形态（攻击/终结的出口）

玄幻攻击的杀伤不靠拳脚接触，靠**能量具象化**。四种高价值形态：

| 形态 | 写法 | 示例 |
|---|---|---|
| **光柱/光路** | 从法器/法阵射向目标，标注范围与破坏 | 百丈白光柱天降、万道金光暴雨 |
| **具象生物** | 灵气聚形（雷龙/火龙/剑灵），标注材质与轨迹 | 雷龙咆哮冲阵、留焦黑轨迹 |
| **巨型化/法相** | 法宝放大（能量巨扇）或身后法相，标注镇压动作 | 巨扇九天镇压而下 |
| **领域/道域** | 法阵铺展+空间扭曲，标注天地异象 | 音波花涡吞没战场、道纹光轮嵌套 |

**能量汇聚前奏（可选）**：天地灵气向角色汇聚（花草灵韵涌来、灵气漩涡成型、能量漩涡吸收），可再接终招，也可按剧情省略——参见 `anime-ultimate-vfx-paradigm.md` 三段式。

### 能量形态的按需澄清

保留剧情已确定的光柱、波纹、雷电或其他形态。必要时写清发出位置、尺度、传播方向、边缘变化和对环境的可见作用；只补本镜需要的信息。不能仅因写了“光柱”，自动替换为巨扇、龙或另一种技能。不对关键词扫描后机械替换，实际异常按该次图像或视频结果定位。

### 冰系终结三拍：冻结 → 崩解 → 余烬（2026-09-04 吸收）

> 冰系终结可选以下三拍，也可停在冻结、破裂或悬念状态；以剧情与出板A为准，不强制崩解目标：

1. **冻结**：绝对零度冰霜自接触点爆发蔓延，目标连同学到的介质被瞬息封入半透明冰晶（内部可见目标姿态）；
2. **崩解**：冰体沿应力纹路龟裂 → 整体崩解为亿万冰晶碎屑，碎屑带折射光缓慢悬浮/坠落——画面是动的；
3. **余烬**：细碎冰尘如余烬飘散沉降，接触点残留霜纹地面，角色收招。

## 五、 对军清场级战斗（战场法则）

玄幻法术流常打"一人对军"的大战场，与武侠 1v1 不同：

- **敌方规模**：亿万修士军阵 / 大军如潮水铺天盖地 / 军阵节节溃散；
- **群杀方式**：扇形冲击波掀飞数十人、剑气暴雨洗地、能量扇镇压大军核心；
- **战场破坏反馈**：地面千疮百孔、陨石坑、弹坑、法宝碎片散落、云层撕开缺口、丁达尔光柱；
- **终结级天罚**：天罚光柱/巨形能量核/道域镇压，落地即陨石坑级爆炸、冲击波球形扩散、所过之处夷为平地。

## 六、 玄幻特有动作链速查（替代拳脚动作链）

| 动作 | 写法 |
|---|---|
| **结印** | 左手结印右手持器，双管齐下 |
| **抛器放大** | 将法宝抛向空中，迅速放大化作巨型能量体 |
| **瞬移残影** | 原地留残影，真身已至 N 丈之外 |
| **灵气汇聚** | 天地灵韵向角色/法宝汇聚，形成能量漩涡 |
| **破罡** | 护体罡气如同薄纸被轻易划开 |
| **防御转攻** | 防御术法炸裂，化作千万攻击飞刃/剑气 |
| **天罚降临** | 高举法器朝天，能量漩涡成型，劈下巨型光柱 |
| **360° 环绕** | 环绕拍摄悬浮主角，能量风暴吹拂衣袂，挥器放出暴雨级攻击 |

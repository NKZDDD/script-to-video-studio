# 文戏表演与对白协同

依据story-directed-performance.md从当前剧情和人物行为设计，不使用六阶段情绪路线、固定情绪动作配方或整套身体反应。表演顺序由事件与对方反应决定，不要求触发后先掩饰、再泄露、再破防。

## 对话双方都在场

对白是人物在当前情境中的行为。明确正在对谁说、希望产生什么作用，以及听者如何接收；不默认说话者每句都占镜头。听者反应有新信息、关系变化或选择时才强调，避免为填满时长反复表现同一情绪。

声音、视线、呼吸、停顿、表情、手部与身体动作根据当下目的协同选择，可以说得平静而行动坚决，也可以直接表达情绪；不强求口是心非或每句都有隐藏意图。沉默、继续做事、不回应都可按情境成立，不把行为清单当表单。

## 对白时间与连续性

- 语速依据人物、情境和可听性估算；普通对白约3.5～5字/秒仅作内部参考，详见dialogue-speed-check。
- 自然落口、呼吸与有意义的停顿均计入预算；同期动作和对白不重复相加。不靠不自然加速、延长反应或重复小动作填满SEG。
- 表情可在说话中变化，也可跨镜保持。对白是否完整以声音及口型核对，表情提前结束不等于吞词；内心独白保持画内嘴闭。
- 镜头可从行为已经开始处进入，也可在状态尚未消退时退出；进入退出须保留观众理解和段间接续所需信息，不强制逐镜完成动作全周期。
- 仪式、舞蹈等连续行为按实际动作关系和可见部位描述，不固定每拍四个部位同时动作；有转身、持物或位移时保持空间与轴线可解释。

表演影响分段或端点时，复核自然时长，再同步母图、ABC与视频文字。分析理由只留内部；输出继续沿用model-adapters的分行对白格式。

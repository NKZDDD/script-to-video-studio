本规范提炼自行业爆款 AI 漫剧“大招蓄力与法阵爆发”提示词工程（如《人物大招系列》即梦 / Seedance 2.0 16:9 与 9:16 工业模版）。

## 一、 15 秒大招三段式节奏结构

下列三阶段是内部设计示例，不要求每个大招完整套用；剧情可以省略蓄力、直接爆发或延长余波。用户、角色能力、ABC与模型适配优先：

```
┌──────────────────────────┬──────────────────────────┬──────────────────────────┐
│ 阶段 1：大招蓄力 (0-3s)   │ 阶段 2：法阵展开 (3-8s)   │ 阶段 3：终极爆发 (8-15s) │
│ 特写微距 + 极速环绕升镜   │ 全景拉远 + 空间扭曲畸变   │ 巨型法相/火龙卷 + 爆音终帧│
└──────────────────────────┴──────────────────────────┴──────────────────────────┘
```

### 1. 阶段一：大招蓄力与微距拉升（0~3 秒，抓眼球）
* **镜头运镜**：极低角度微推 $\rightarrow$ 特写极速环绕拉升 $\rightarrow$ 定格人物全身（是否微停顿或持续运动按叙事决定，不自动冻结）。
* **微观动作**：手腕猛旋、指尖余火缠成暗角、掌心太古签纹极转、足尖点噬火浪、收焰聚于掌心、青筋暴突、眼眸神光爆绽。
* **特效细节**：掌心凝刃、“主色+副色”双色波涌燃炼、金羽凝结、空气扭曲、碎石浮空。
* **音效设计**：开场声音按剧情选择： 尖锐火雷声/破空剑鸣 + 地面低频轰鸣，0.5 秒特写抖动蓄势，瞬间拉满压迫感。

### 2. 阶段二：法阵展开与空间异象（3~8 秒，造奇观）
* **镜头运镜**：低角度微推 $\rightarrow$ 全景平稳抬升拉远 $\rightarrow$ 俯瞰空间格局。
* **空间动作**：单手擎天/虚空悬浮、身姿沉稳傲慢、尊袍随狂风神风傲然扬动、俯视冷冽。
* **法阵与异象**：亿万符文如火龙盘旋漫天泼洒、空间随阵法剧烈扭曲崩折、千道法纹铺满夜空顶、地面龟裂透出熔岩/雷光。
* **音效设计**：弦乐拉满 + 重音震底，法阵展开伴随漫天雷鸣轰鸣，节奏持续攀升。

### 3. 阶段三：终极爆发与道域镇压（8~15 秒，情绪高潮）
* **镜头运镜选例**：大广角全景 $\rightarrow$ 推向爆发核心 $\rightarrow$ 冲击波余波延续；实际结尾按剧情和交接状态决定，不默认冻结。
* **终结绝杀**：凝聚十道巨型火龙卷/万剑归宗/黑渊禁区，碾碎漫天虚空，天地恒压无极。
* **音效设计**：重低音音爆轰炸，余音回荡，收尾可选爆点、余波或悬念；仅在该边界启用ABC出板时服从出板A，无关联天然转场免板。无论是否用板，都保持对白完整落口和声音边界清楚。

### 4. FPV 主观穿梭机位（万剑/弹幕级大招专用）
> 学自 35s 玄幻秒级拆解：大招释放段的“弹幕式”攻击（万剑齐发/箭雨/光弹），用**跟随第一排攻击的 FPV 主观俯冲**，比旁观全景更有代入感。
* **写法**：跟随第一排飞剑超高速向前俯冲，攻击如暴雨倾泻，呈地毯式火力压制；
* **配套**：极速运动模糊 + 攻击划破云雾/熔岩地面 + 密集机枪破空尖啸音效（Supersonic Barrage）。

### 5. 短蓄力仪式感（慢/滞段·慎用升格）
慢镜、短促凝神或连续运动均可选；根据用户要求、剧情和模型适配决定，不将慢镜设为全局禁令。
* **写法（紧凑版）**：面部推镜 $\rightarrow$ 拉开仰视全身，能量急剧坍缩成核，阴阳双龙盘旋成太极图（黑龙盘暗黑旋涡 + 白龙绕光明风暴 + 中央持兵）；
* **配套示例**：沉浑龙吟与交响可用于蓄力，镜头数、时长和是否紧接爆发由剧情确定。

### 6. 天地级异象（神魔/法相终极形态）
> 玄幻天花板级大招：**通天神魔巨躯**拔地而起，半身烈日半身熔岩，背后神环轮转，手托擎天巨刃；下方山脉与人物如蝼蚁微尘。
* **能量坍缩**：狂暴雷火向枪尖急剧坍缩凝聚为一点，空间产生引力透镜扭曲（背景岩石被拉长、光带弯折）；
* **灭世收尾**：神兵直插大地，地核能量柱如核爆贯穿天穹，大陆板块断裂，金红光浪横扫大陆，天际照亮成白昼，终帧高斯模糊+震屏。

## 二、 双色粒子与高级质感配色铁律

1. **双色缠绕原则**：
   * 单色或双色按已锁定技能资产选择；需要双色时可用主色+副色互补或渐变，例如：
     * `赤红 + 暗金`（熔岩尊者、烈阳神明）
     * `玄黑 + 幽紫`（暗夜深渊、魔道至尊）
     * `冰蓝 + 银白`（霜雪剑圣、寒月仙尊）
     * `苍青 + 鎏金`（太古道祖、东方修仙）
2. **UE5 级渲染与环境物理参数**：
   * 仅当项目锁定UE/PBR写实风格时可参考；不得覆盖2.5D、水墨或其他视觉媒介：`UE5风格光照，体积雾，抽象不可读符纹流动、光芒微闪，材质颗粒可见`。分辨率按实际生成配置，不以“8K”字样承诺输出规格。

## 四、 去水五律（粒子/光效防"水"铁律·2026-09-02 实测固化）

> 以下是处理光效含混时的描述工具；不能由个别失败推断所有模型的固定表现。先检查实际结果，再决定是否补充材质、密度和运动描述，不把五项全部强加给每个镜头。

1. **可执行描述**：评价词不能代替关键可见事实；按需要说明动作、形态与材质，风格和技术参数按实际用途保留，不推断所有模型都无法理解某词。
2. **澄清光效**：当光柱、法阵、能量球或光束含混时，按需补充形态、构成、边缘、运动或密度中的相关项，不强填四件套；保持原设定的外形、能力和剧情结果。
3. **避免抽象粒子堆词**：需要可读材质时改写作材质比喻——燃烧的铁屑洪流（密度如蜂群）/ 水晶碎屑逆流 / 火星 / 余烬 / 符纸碎屑。重点写出颗粒的材料、密度和运动，而非仅靠术语。
4. **方向与速度**：按实际运动说明，速度反差是可选工具。高速粒子带拖尾光迹（0.2s 划出画面），慢速余烬带沉降弧线（触地即灭）；漂浮、下落、逆流或贴地游走均须符合设定。
5. **能量过程示例（压缩→爆发→余波）**：选择蓄力时可写"逆向收束"（粒子像磁吸铁屑向核心压缩，衣袂发丝被吸向能量场），也可按技能设计采用其他积累方式；爆发写核心破裂+冲击波环；余波写烟尘膨胀+余烬沉降。

## 六、 双属性对冲与绝杀收尾范式（2026-09-04 吸收）

### 1. 双属性对冲成太极图案炸散
- 两属性能量对冲时，避免只有裸词；一种可选写法是**两股属性流旋拧交缠成太极图案，旋转加速至临界后整体炸散**；
- 写法要素：双色流体螺旋缠绕 → 图案成型（阴阳双鱼咬合轮转）→ 临界过载 → 图案崩裂炸散为漫天双色光屑；
- 对冲双方沿用已锁定资产。辨识度可来自外形、材质、动作路径、明暗或色彩；按剧情选取，不强制双色或高反差互补。见 `seedance-render-engine.md` 的创作决策。

### 2. 能量吞屏切黑结尾（绝杀专用收束）
- 无关联终篇可选：**能量光浪吞没全屏 → 切黑 → 环境余声收束**（碎石滚落/风声/耳鸣）；
- 三拍结构：命中爆闪（吞屏白/属性色）→ 纯黑 0.3~0.5s → 余响渐起；
- 这是一种收束方案，平静全景或动态余波也可按剧情采用；有承接需求时不能擅自切黑，优先对应出板A。

空间补充：本例入板C承担开场空间，不重复上传另一张布局图；角色参考只补身份外观。共同母图、一次生成整板与跨区视角核对按 `abc-handoff-board.md` §1.1。

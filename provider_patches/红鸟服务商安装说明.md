# 红鸟服务商外挂

适用于支持 `providers` 外挂的 Respect Studio。外挂名称为“红鸟”，默认接口地址为 `https://an.hongniaoai.com/api`。

## 安装

1. 将 `hongniao.py` 放入当前 Studio **数据目录**下的 `providers` 文件夹。数据目录以程序启动时显示的位置为准；使用了 `--data` 的，放进指定目录。已有其他外挂保留。
2. 在“设置 → 服务商”点击“重新扫描服务商”，或者重启 Studio。
3. 选择“红鸟”，填写自己的 API Key，点击“保存服务商设置”。本文件及压缩包不含任何 Key。
4. 回到生产页面，在分段视频的服务商中选择“红鸟”，选择模型和时长，检查生产计划后开始。

## 当前模型

| 模型 | 时长 | 参考图 | 参考视频 / 音频 |
|---|---|---|---|
| minimax-h3-768-933 | 4–15 秒 | 最多 9 张 | 各 3 份 |
| wan3-720p | 4–30 秒 | 最多 10 张 | 各 5 份 |
| video-standard-720p | 4–15 秒 | 最多 9 张 | 各 3 份 |
| video-sd25-30s | 5、10、30 秒 | 最多 30 张 | 未声明支持 |
| video-sd25-480p | 4–30 秒 | 最多 30 张 | 各 10 份 |

以上为 2026-09-23 红鸟模型接口实际返回的声明，默认选择 `video-sd25-30s`。参考图片支持公网 URL 或 Data URI；参考视频与音频需要公网 URL。当前接入仅支持视频。

## 旧 EXE 与新版源码

旧 EXE 安装此文件后会显示上述模型，可以使用生产入口。旧版“检查连接 / 刷新模型”只认识其他服务商的数组格式，可能提示“接口未返回模型数组”；该提示不能用于判断红鸟 Key 无效。

本次新版 Studio 源码已经适配红鸟的 `data.models` 格式和逐模型参数。要在页面实时刷新红鸟模型，需要使用包含此次更新的新版 EXE；仅复制外挂不会替换旧版模型目录解析器。

## 任务与结果

提交后记录服务商任务 ID，并查询同一任务。任务已完成但缺少视频地址、下载失败或查询超时，会明确报错并保留任务 ID，不自动重新创建付费任务。原始提交未取得可靠回执时，会显示订单号，先到红鸟核对是否已创建。

已验证真实鉴权与模型查询，并用本地模拟接口验证任务提交、轮询、文件下载和错误处理；未提交付费生成任务。

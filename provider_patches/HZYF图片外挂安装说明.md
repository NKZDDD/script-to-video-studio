# HZYF hzyfai.com 图片服务商外挂

版本：20261004.1。支持 Studio 的 providers 外挂机制；不含 API Key，无需安装 Python，不用更换 EXE。

## 安装

1. 解压本包，在 Studio 的「设置 → 服务商」点击「导入服务商文件…」，选择 `providers/zz_hzyfai_image.py`。
2. 导入后会重新扫描服务商；若页面仍显示旧选项，刷新页面。已有 HZYF Key 保留，不用重新填写。
3. 如果旧版没有导入按钮：等当前生产结束后退出 Studio，把同名文件放到实际数据目录的 `providers` 文件夹，再启动。不是项目素材文件夹，也不是随意放在 EXE 旁边。
4. 基址可填 `https://hzyfai.com` 或 `https://hzyfai.com/v1`，不会重复拼接 v1。
5. 在图片生产行选择 HZYF、模型 `gpt-image-2`、比例 `4096x4096`、清晰度 `4K`，重新查看生产计划后开始。也可以只选择 `4096x4096`，清晰度保留「跟随任务」（任务本身不要有其他清晰度覆盖）。

例如数据目录为 `D:\stv-data`，文件路径应为 `D:\stv-data\providers\zz_hzyfai_image.py`。
若服务商未出现，检查实际数据目录、.py 后缀和设置页的外挂加载错误。

## 模型与参数

- `gpt-image-2`
- `gpt-image-2.5`
- `gpt-image-2.5-flare`
- `gpt-image-2.5-sunburst`

本次接入图片能力，不声明视频或聊天能力。
原尺寸选项：`1024x1024`（方图）、`1536x1024`（横图）、`1024x1536`（竖图）。
本次增加 `gpt-image-2` 的 `4096x4096` 方图及清晰度 `4K`。接口实际发送 `size=4096x4096`，不发送未经验证的独立 `resolution=4K` 字段。
清晰度选 4K、比例为 1024x1024 时也会等比例升级为 4096x4096。横图/竖图不强改为方图，需明确选择已验证的方图尺寸。
本次真实 4K 验证只覆盖 gpt-image-2 方图文生图；其余三个模型及横竖 4K 尚未验证，暂不宣称支持。图生图沿用同一 size 参数，已检查 multipart 请求透传，未新增付费 4K 编辑实测。
旧任务如带有其他 resolution 参数，应清空该字段或选择已支持的覆盖档位。

文生图：POST `/v1/images/generations`，JSON。
图生图：POST `/v1/images/edits`，multipart 重复 `image[]` 字段。
本地图片直接上传，不需要对象存储；上传前检查完整性，以实际图片内容决定 MIME。
不在本地按 9 张截断或拦截，服务端的实际素材限制仍以响应为准。
支持同步返回 URL 和 Base64，结果经下载与文件检查后才标记完成。

## 错误与兼容边界

- `insufficient_user_quota` / HTTP 403：所属账户余额不足。
- `system_cpu_overloaded` / HTTP 503：服务商网关负载过高，稍后再试。
- 当前实测图片请求同步返回结果；request_id 是追踪编号，不当作可轮询 task ID。未验证异步任务查询接口，不承诺按 request_id 恢复历史任务。
- 只扩展 HZYF，不修改其他服务商、全局任务管理或用户密钥。
- 主程序源码已同步，但此前的 20261003 EXE 尚未内置 4K；在该版上需要保留本外挂。只有确认后续 EXE 已内置本版能力后，才可移走本外挂。
- 以后同类服务商模型、尺寸、接口参数更新可以通过更新这个 .py 外挂导入；页面结构和全局生产流程变更仍需更新主程序。

撤销：退出 Studio 后将 zz_hzyfai_image.py 移出 providers 并重启，保留项目和配置。

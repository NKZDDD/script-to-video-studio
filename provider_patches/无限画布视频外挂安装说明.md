# 无限画布视频模型更新外挂 2026-10-09

适用于支持服务商外挂的 Respect Studio。本包更新现有“无限画布”，沿用原 Key 配置；不需要重新打 EXE，不包含 Key。

## 推荐安装方式

1. 解压本 ZIP。
2. Studio → 设置 → 服务商 → 导入服务商文件，选择 providers/zz_wuxianhuabu_latest.py（不要选择整个 ZIP）。
3. 选择“无限画布 videogogo.top”，填写自己的视频分组 Key，Base URL 为 https://videogogo.top/api 。已有 Key 不用重复填。
4. 点击“检查连接 / 刷新模型”，回生产页选择具体视频模型和参数；正在运行的旧批次继续使用启动时的配置。

旧界面没有导入按钮时，把 .py 放进当前数据目录的 providers 文件夹，重启 Studio 或点击“重新扫描服务商”。不是放进项目目录。若已有其他无限画布旧外挂，请先移到 providers 文件夹外备份，避免同时覆盖同一家服务商。

## 本次内容

- 同步 13 个视频型号；保留旧任务的已知参数与原查询/下载方式。
- 按型号提供比例、清晰度、秒数和图片/视频/音频参考限制。Dola 的 5、10、30 秒是三个档位；video-sd25-30s 只声明 10、30 秒。
- 完整发送参考素材，超过模型明确上限会在提交前报错，不会悄悄丢图。未公布数量时不添加本地上限。
- 防止旧 EXE 自带的 9 月快照隐藏新增型号。旧清单可能仍保留兼容名称，填 Key 后刷新模型即可取得当前目录；请优先选择下表型号。
- 当前 Studio 的参考图片仍走上传副本体积处理，原图不覆盖。

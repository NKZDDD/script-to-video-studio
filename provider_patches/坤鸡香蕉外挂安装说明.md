# 坤鸡香蕉模型更新外挂

版本：20261008.1。用于已有 Studio EXE，无需重新打包主程序。

## 支持的香蕉模型

- `gemini-nano-banana-2.1`
- `gemini-3-pro-image`
- `gemini-3-pro-image-preview`
- `gemini-3.1-flash-image`
- `gemini-3.1-flash-image-preview`

这五个名称均来自 2026-10-08 香蕉分组 Key 的实时模型列表。香蕉 2.1 已实际生成一张 1024×1024 JPEG，耗时 28.6 秒。其余型号的新增路由采用离线测试，未逐一收费生成；2K/4K 未在本次实际生成验证。

旧适配器仅将两个 preview 名称识别为香蕉，新名称会误走 OpenAI images 接口。本外挂将上述五个型号统一送到 Gemini generateContent，参考图继续按 inline_data/file_data 传递，使用现有图片保存逻辑。

## 安装和使用

1. 等待正在执行的任务结束，退出 Studio。
2. 找到 Studio **实际数据目录**：设置页的外挂目录为准。默认通常是 `%LOCALAPPDATA%\Respect-Studio\providers`；若配置放在 EXE 旁或启动时指定了 `--data`，应使用对应数据目录内的 `providers`。
3. 把压缩包中的 `providers/zz_kunji_latest.py` 放进该文件夹。已有同名文件则覆盖；其他旧坤鸡外挂先移到 `providers` 之外备份，避免后加载的文件覆盖本补丁。不要删除其他服务商外挂。
4. 重启 Studio，确认坤鸡来源显示 `zz_kunji_latest.py`。服务商仍叫“坤鸡 img.yunfei.best（图片 + veo视频）”。
5. 使用已授权香蕉模型的 Key。当前页面按尺寸挑选 Key：先测试 1K 时，将香蕉 Key 填入坤鸡的“图片 1K Key”，生产中尺寸选 **1K**，模型选 `gemini-nano-banana-2.1`。这会替换该槽位原来的 Key；已有 GPT 分组 Key 请自行保留，不能用 GPT 分组 Key 代替香蕉权限。
6. 如果下拉列表仍旧，保存 Key 后点击“拉取最新模型”，再选择上面的准确名称。更老版本也可以在可编辑的模型框手填准确名称。

本包不含任何 Key，不自动修改本机配置。主程序源码已同步更新。现有 GPT 图片、Veo 视频和参考图数量规则保持原有行为；本次只补齐香蕉名称、协议路由与目录兼容。

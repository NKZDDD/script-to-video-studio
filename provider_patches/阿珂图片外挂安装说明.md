# 阿珂图片外挂

版本：20260930.1。供支持 `providers/` 外挂的 Studio 使用，无需安装 Python；不含 API Key。

## 安装

1. 等正在生产的任务结束，退出 Studio。
2. 在设置页或启动窗口确认实际“数据目录”，把 `zz_ake_image.py` 放到该目录的 `providers` 文件夹，没有则新建。
3. 如果已有其他阿珂外挂，先将旧阿珂 `.py` 文件移出 providers 备份；其他服务商文件保留。
4. 重启 Studio，在设置里确认阿珂的来源是 `zz_ake_image.py`。“覆盖已有同名服务商”属于正常提示。
5. 使用原来的阿珂 Key；未配置过则在阿珂服务商设置中填写。网关为 `https://snumom.com`。
6. 图片生产行选择“阿珂 snumom.com”，再选图片模型与尺寸。

例如数据目录是 `D:\stv-data`，文件应为 `D:\stv-data\providers\zz_ake_image.py`。
默认安装常见位置为 `%LOCALAPPDATA%\Respect-Studio\providers`，以程序显示的实际目录为准。
不要放到项目素材目录。只有实际数据目录就是 EXE 所在目录时，才放在 EXE 旁的 providers。

## 图片模型与尺寸

| 模型 | 尺寸 | 清晰度 |
| --- | --- | --- |
| gpt-image-2 | 2048x2048 | 2K 方图 |
| gpt-image-2 | 3840x2160 | 原生 4K 横图 |
| grok-imagine-image-2.0 | 1024x1024 | 1K 方图 |

建议先直接选尺寸，清晰度保留“跟随任务”。如选 4K，尺寸同时选 3840x2160。
这些是官网目前明确公布的尺寸；gpt-image-2 不接受 4096x4096。
原项目若要求竖图，生产计划会提示尺寸不兼容，可在对应生产行明确选择受支持的尺寸，或使用支持竖图的服务商。

图片参考素材按文件上传，不需要配置对象存储；参考图按实际顺序全部发送，不截断。
文档只展示单图示例，未公布参考图数量上限；多图使用重复 image 字段，其实际支持情况以服务商响应为准。
已有视频能力保留，视频参考素材仍需要公网 URL。

# 沧元图片与视频外挂 · 2026-10-13

本包有两个独立入口：沧元算力（图像）32 个模型、沧元算力（视频）34 个模型。
已用用户新 Key 只读查询目录，HTTP 200；未发起付费生成。支持目录不等于各上游实时生成成功。
本包不含 Key；全能力 Key 可以分别填在两个入口。视频旧 Key 仅有视频权限时，不能用来生成图片。

## 安装

1. Studio → 设置 → 服务商与密钥 → 导入服务商文件，依次选择：
   - `providers/zz_cangyuan.py`
   - `providers/zz_cangyuan_video.py`
2. 分别选择“沧元算力（图像）”和“沧元算力（视频）”，填写全能力 Key 并保存。
3. Base URL 均为 `https://ai.cangyuansuanli.cn`（填写带 `/v1` 的地址也会自动规范化）。
4. 检查连接 / 刷新模型，回生产页选择服务商与具体型号。

没有导入按钮的旧版：将两个 `.py` 放入**设置页显示的数据目录**下的 `providers` 文件夹，再重启 Studio。
例如数据目录为 `D:\自动化工具`，则放到 `D:\自动化工具\providers`，不要放到生产项目目录或 `_MEI` 临时目录。
如装有其他同 ID 的旧沧元外挂，先移到 `providers` 目录外备份，避免旧文件覆盖新适配器。
2026-10-13 新 EXE 已内置同一份代码，不需要重复装本包。

## 参数与取回

- `sd11-seedance-2.5`：4–30 秒，参考图片 30 张、视频 10 个、音频 10 个。
- `sd10-seedance-2.5`：固定 30 秒，只接收参考图；`sd13-seedance-2.5` 不接收参考音频。
- `sd8-seedance-2.5-s`：固定 30 秒、720p。模型名含清晰度的固定通道不会偷偷切换型号。
- `kl1-kling-3.0` 的一/两张参考图，按上传顺序分别作为首帧/尾帧；不能额外混入其他参考。
- 参考数量按官方逐模型文档；超过明确上限会报错，不静默截断。没有统一九图限制。
- 图片 `nano-banana2-4k` 支持 16 张参考图；新增 `doubao-seedream-5-0-flash`，支持 10 张参考图。
- 分辨率、比例和像素尺寸按模型文档传递；JPEG/PNG 结果沿用 Studio 的图片解码与格式归一化。
- 本机参考图片需要配置对象存储成为 HTTPS URL。新版 Studio 上传副本按不超过 9.5 MB 处理，原图不覆盖。很旧的 EXE 没有共用压缩功能时，请使用新 EXE 或先压缩上传副本。
- 参考视频/首尾帧协议已适配；外挂不新增旧版 Studio 没有的素材编辑界面。参考音频使用 Studio 现有音频入口。
- 创建成功会保存任务 ID；查询/下载异常下次续查原 ID，不再创建。服务商明确生成失败由新版 Studio 标记失败，下次提交使用新参数。
- 当前批次使用启动时的配置快照，新增/换 Key 请在下一批使用。

目录、逐模型文档来源：<https://ai.cangyuansuanli.cn/docs>，读取时间 2026-10-13。
包内 `models.json` 记录本次可见目录，`model-parameters.json` 记录图片视频能力，不含凭据。
